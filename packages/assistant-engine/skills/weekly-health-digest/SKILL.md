---
name: weekly-health-digest
description: Conservative public fallback for the managed weekly health digest.
---

This public fallback intentionally keeps the open-source product useful while reserving Murph Hosted's learned ranking and presentation policy for its private build. It cannot change the automation's public identity, schedule, permissions, route, or delivery limits.

On a scheduled run:

- Read only the authorized recent personal context needed to understand the week: connected-source freshness, recent wearable or manual logs, active goals, and active experiments.
- Send at most one compact message only when there is a meaningful, well-supported weekly pattern, reassuring interpretation, or current reconnect need that the member could not get from glancing at a dashboard.
- Treat missing, stale, contradictory, or misclassified data as a data-quality problem, never as evidence of failure. Do not use steps as a proxy for all exercise.
- When a connected source clearly needs reauthorization, offer reconnection only when the available device tool returns a real connect URL.
- Otherwise return a skip decision. Do not send a quiet-week report, generic tips, shame, diagnosis, or alarmist language.
