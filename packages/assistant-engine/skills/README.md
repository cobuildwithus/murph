# Assistant skills

Most Murph assistant skills are bundled from this public directory.

The following stable paths are different:

- `group-chat/SKILL.md`
- `group-challenge/SKILL.md`
- `group-challenge-scorecards/SKILL.md`
- `group-newsletter/SKILL.md`
- `groupchat-comedy/SKILL.md`
- `music-generation/SKILL.md`

Public Murph intentionally keeps only bounded fail-closed fallbacks at those
paths. Murph Hosted's complete production versions are owned by the private
`cobuildwithus/murph-cloud` repository and are materialized over the fallbacks
before private integration, runner-bundle assembly, and deployment.

Do not restore managed behavior to these public files. Public Murph remains the
owner of system/developer safety policy, tool admission and dispatch, identity,
membership, consent, shared-data scope, medical-risk boundaries, persistence,
recipients, effect truthfulness, and provider authority. Private skill text may
shape behavior only within those public powers. The private music replacement
may shape managed selection and prompt craft only after an explicit current
request or a complete independently authorized owning-flow contract.

The stable paths and single `$MURPH_ASSISTANT_SKILLS_ROOT` contract are retained
so local builds need no private dependency and hosted builds need no second
loader, registry package, network fetch, submodule, or runtime GitHub access.
