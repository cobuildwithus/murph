# Group Challenge Scorecards

Murph Hosted's production team, collective-target, multi-metric, and weighted
scorecard behavior is installed from the private `cobuildwithus/murph-cloud`
repository during the trusted hosted build.

This public fallback intentionally contains no managed scorecard policy. Use
only public runtime contracts and exact admitted group data. Do not invent
components, weights, participants, scores, permissions, or settled results. If
the current build cannot load the managed policy, explain that advanced group
scorecards are unavailable rather than approximating them.
