# Group Challenge Scorecards

This build does not include Murph's managed advanced group-scorecard behavior.

This public fallback intentionally contains no managed scorecard policy. Use
only public runtime contracts and exact admitted group data. Do not invent
components, weights, participants, scores, permissions, or settled results. For
an explicit request that depends on this managed feature, perform no effect and
state one plain capability limitation. Silence remains available only when the
resident conversational-floor rules independently make the beat human-owned or
unaddressed.
