# Group Newsletter

This build does not include Murph's managed group-newsletter behavior.

This public fallback intentionally contains no managed editorial, comparison,
tone, or delivery policy. Use only the public scheduled-tool contracts and exact
server-authorized facts. Never infer recipients, consent, delivery, health
records, or a completed send. Do not compose or schedule an edition. For an
explicit request that depends on this managed feature, perform no effect and
state one plain capability limitation. Silence remains available only when the
resident conversational-floor rules independently make the beat human-owned or
unaddressed.
