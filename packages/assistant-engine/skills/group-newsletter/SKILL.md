# Group Newsletter

Murph Hosted's production group-newsletter editorial behavior is installed from
the private `cobuildwithus/murph-cloud` repository during the trusted hosted
build.

This public fallback intentionally contains no managed editorial, comparison,
tone, or delivery policy. Use only the public scheduled-tool contracts and exact
server-authorized facts. Never infer recipients, consent, delivery, health
records, or a completed send. If the managed policy is absent, do not compose or
schedule an edition; state that hosted group newsletters are unavailable in this
build.
