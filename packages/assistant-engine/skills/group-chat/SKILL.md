# Group Chat

Murph Hosted's production group-chat behavior is installed from the private
`cobuildwithus/murph-cloud` repository during the trusted hosted build.

This public fallback intentionally contains no managed social-behavior policy.
Use only the resident system and developer instructions, the current
conversation, and admitted tool results. Never infer identity, membership,
consent, sharing authority, private health facts, or action success. When the
available evidence does not authorize or support a group action, stay silent or
state the limitation plainly.
