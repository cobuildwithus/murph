# User-facing response templates

Use these as shapes, not scripts. Keep the interaction conversational, reuse vault context, and omit sections that do not apply.

## Enough context: start helping

```text
This still looks most compatible with [working pattern], based on [one or two key facts]. I’m using your existing goal of [goal] and the prior baseline of [baseline].

For the next [two/three] comparable exposures:
- Load: [specific adjustment]
- [Exercise/exposure]: [dose and cue]
- [Exercise/exposure]: [dose and cue]

Green: [acceptable response]
Yellow: [hold/reduce rule]
Red: [specific stop/escalation rule]

Recheck [same baseline] after [review trigger].
```

## One plan-changing gap

```text
The gradual onset and [trigger/response] still fit a stable load-related pattern. One thing changes the starting plan: [single targeted question]?

Until then, [safe reversible action that does not depend on the answer].
```

## Recurrence: delta only

```text
I’m using the prior episode, goal, and last tolerated dose. Tell me only what is materially different this time—especially [one pattern-relevant change]. If nothing changed, restart one step below the last green dose and compare the next morning.
```

## Targeted safety clarification

```text
Because you mentioned [specific cue], one current detail changes whether exercises are appropriate: [one compact pattern-specific question]?

Until that is clear, [safe interim action].
```

Do not append unrelated warning-sign categories.

## Pattern summary

```text
What this currently looks most compatible with:
- [working pattern], with [low/moderate/relatively high] confidence

Why:
- [supporting features]

What keeps me cautious:
- [conflicting/missing feature or important alternative]

What would change the plan:
- [specific new symptom or observation]
```

## Bounded starter plan

```text
Goal and baseline:
- [target task]
- [current repeatable threshold/rating]

For the next [exposures/time window]:
1. Load change — [specific reduce/maintain/substitute decision]
2. [Exercise/exposure] — [purpose, setup, dose, cue]
3. [Exercise/exposure] — [purpose, setup, dose, cue]

Green:
- [acceptable response]

Yellow:
- [hold or reduce one variable]

Red:
- [stop and seek/reassess]

Check in after:
- [number of comparable exposures/date]
- use the stored log; ask only for the missing decision-changing detail
```

## Follow-up with sufficient logs

```text
Your log shows [response and baseline change]. That supports [primary decision].

Change one variable:
- [specific progression/regression]

Keep stable:
- [other variables]

Tell me only if [specific next-morning or pattern-change off-ramp].
```

## Referral

```text
Because you reported [specific finding], exercises are not the right first step. Please seek [emergency/same-day/prompt/routine] assessment. [One concise escalation instruction if relevant.]

I can prepare a short handoff using the history, baseline, prior plan, and response already in your vault.
```
