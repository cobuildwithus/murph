# Running/cardio programming reference

Use this file when constructing or changing a plan. Keep the user-facing answer simpler than this reference.

## Architecture

Every plan should be expressible as:

`mode + weekly structure + session types + modifiers + one progression lever + review`

Do not add a plan template for each goal, modality, or schedule. The same structure should handle running, cycling, rowing, incline walking, elliptical, swimming, and mixed-modality cardio.

## Mode selection

| Mode | Use when | Main adaptation | Default bias |
|---|---|---|---|
| Start/restart | Beginner, deconditioned, ordinary pain-free return, uncertain impact tolerance | Repeatability and tolerance | Easy, short, conservative |
| Build base | Aerobic capacity, Zone 2, endurance, less breathlessness, more weekly volume | Sustainable aerobic work | Mostly easy; optional longer easy |
| Develop | Stable recent base plus non-event tempo, speed, hill, or VO2 goal | One targeted quality stimulus | One quality session; easy work around it |
| Support/maintain | Strength or sport leads, life is constrained, travel, minimal equipment, maintenance | Preserve the most valuable stimulus | Minimum effective structure |

A plan may change modes over time, but one mode should own the current block. Modifiers do not create new modes.

## Plan horizon and calibration

Answer the horizon the user asks for. A longer plan may still begin with a one- or two-week calibration phase when baseline or recovery is uncertain.

Calibration is not a throwaway plan. It should establish:
- whether prescribed easy effort is genuinely easy
- whether the session length is repeatable
- whether running impact is tolerated
- whether the weekly schedule survives ordinary life
- whether hard sport or lifting has been undercounted

After calibration, progress the existing plan instead of replacing it wholesale.

## Weekly composition

### One weekly exposure

Useful for maintaining contact, supporting another sport, or a very constrained period. It usually cannot maximize both aerobic volume and quality.

Choose the single session based on the job:
- easy aerobic for recovery, health, or impact tolerance
- sustained or interval quality for an established user preserving intensity
- mixed easy plus a few relaxed strides when running skill matters

Do not imply that one session is useless.

### Two weekly exposures

A robust minimum for starting, support, or maintenance.

Common compositions:
- easy + easy
- easy + longer easy
- easy + one quality session
- two low-impact sessions around strength or sport

For a beginner runner, keep both easy until impact tolerance and repeatability are established.

### Three weekly exposures

The simplest development structure:
- easy
- quality or easy
- longer easy

Separate running exposures with easier days when impact tolerance is uncertain. A hard sport practice may replace the quality session.

### Four or more weekly exposures

Add easy volume before adding a second quality session. A second quality exposure is appropriate only when:
- recent training is stable
- the user has prior experience at that workload
- recovery and schedule support it
- the two sessions have distinct purposes
- other hard lifting, sport, and conditioning have been counted

Do not chase a numerical intensity-distribution quota in a small recreational week.

## Session types

### 1. Easy aerobic

Purpose:
- aerobic development
- recovery-supportive movement
- volume accumulation
- movement or impact tolerance
- skill and consistency

Prescription ingredients:
- time or distance
- conversational effort
- modality and terrain
- optional run-walk pattern

Examples of structure, not named plans:
- 20–40 minutes continuous at easy effort
- 5 minutes easy, then repeated 2 minutes run / 2 minutes walk, then easy finish
- 30 minutes cycling at full-sentence effort

Easy work should not drift into a disguised tempo session. Slow down, walk, lower resistance, or reduce incline when needed.

### 2. Sustained quality

Purpose:
- improve tolerance of prolonged controlled-hard work
- support threshold-related adaptations
- improve pace or power sustainability

Use when:
- the user has a stable easy routine
- the goal favors sustained output
- the user can recover without losing the rest of the week

Build from repeatable segments before long continuous work. Examples:
- 3 x 6 minutes controlled, 2 minutes easy
- 2 x 10 minutes controlled, 3 minutes easy
- 15–25 minutes total controlled work in shorter pieces

A sustained session is not a time trial. End with the sense that another short repeat was possible with good form.

Progress one lever:
- add a few minutes of total work
- lengthen repetitions while total work remains similar
- shorten recovery modestly
- increase pace/power slightly while effort stays controlled

### 3. Interval quality

Purpose:
- provide a high aerobic or VO2-oriented stimulus
- accumulate quality time at a hard but repeatable output
- improve time efficiency for an established user

Variables include work duration, recovery duration, intensity, number of repetitions, modality, and terrain. There is no single best interval recipe.

Practical starting structures:
- 6 x 1 minute hard / 2 minutes easy
- 5 x 2 minutes hard / 2 minutes easy
- 4 x 3 minutes hard / 3 minutes easy

Choose shorter work or lower-impact modality when running mechanics, tissue load, or local muscular fatigue would limit the intended cardiovascular stimulus.

Quality rules:
- use a progressive warm-up
- first repetition should be controlled
- maintain technique and broadly stable output
- recovery should make the next repetition purposeful
- stop before repeated failure or form collapse

Progress one lever, usually total quality time before intensity.

### 4. Relaxed speed

Purpose:
- preserve or develop running economy, coordination, and comfort at faster movement
- add a small speed exposure without a large metabolic cost

Examples:
- 4–8 x 10–20 seconds relaxed strides with full walking or easy-jog recovery
- 4–8 short gentle-hill accelerations with full recovery

Use only when the user is already tolerating running and has no active pain. “Fast and smooth” is the cue; sprinting and fatigue are not the goal.

## Warm-up and cool-down

Easy sessions often need only a gentle first few minutes.

Quality sessions usually benefit from:
- 8–15 minutes easy movement
- a gradual rise in effort
- modality-specific preparation
- optional short pickups for experienced users

A cool-down can be a few easy minutes. Do not make it ceremonial or mandatory when the user needs to stop safely and feels well.

## Starting dose

Anchor the first week to recent reality:
- recent weekly frequency
- longest comfortable session
- recent running-impact exposure
- recent hard sessions from all training
- schedule and recovery

When no reliable baseline exists:
- choose two or three sessions
- keep them easy
- use duration rather than distance
- make the first session clearly submaximal
- leave at least one easier day between early runs
- review after two or three comparable exposures

Avoid using an aspirational former fitness level as the starting dose after a long break.

## Running-specific progression

Aerobic comfort can improve faster than impact tolerance. For a new or returning runner, a sensible order is usually:
1. comfortable exposure
2. repeatable frequency
3. total easy time or running fraction
4. a modest longer easy session
5. relaxed speed if useful
6. sustained or interval quality

This is a default order, not a rigid prerequisite ladder. An experienced runner returning from a short pain-free break may move faster; an injury return remains owned by physical therapy.

### Run-walk progression

Run-walk is a normal training tool, not a remedial label.

Progress by changing one item:
- total session time
- number of running repetitions
- run interval length
- walk interval length
- weekly frequency

Do not increase all of them together. The user may remain with run-walk indefinitely if it best fits comfort, enjoyment, heat, terrain, or health.

## General progression rules

No universal percentage is a safety guarantee.

Progress when:
- the user completed the intended week or comparable exposures
- session effort matched the prescription
- mechanics remained acceptable
- recovery was normal or predictably manageable
- the schedule still fits

Hold or reduce when:
- easy sessions repeatedly become moderate or hard
- soreness or fatigue persists longer than expected
- sleep, illness, heat, travel, or stress materially changes capacity
- the plan is repeatedly skipped because the dose or timing is wrong
- sport or lifting load increased

Change one main lever at a time. Small, boring progress is acceptable.

## Deloads and easier weeks

Do not force a fixed deload calendar for every recreational user. Use an easier week when accumulated fatigue, schedule, travel, illness, or a completed development block makes it useful.

An easier week can reduce:
- total time
- quality volume
- running impact
- session frequency

Keep a small amount of familiar movement or intensity only when it supports recovery and confidence.

## Support and maintenance

Maintenance is goal- and time-specific. It should preserve the highest-value stimulus with less total work, not promise indefinite fitness retention.

For a short constrained period:
- keep one or two easy exposures
- retain a small quality exposure when the user already tolerates it and performance matters
- favor familiar modalities and workouts
- avoid adding novel impact or external load

On return to fuller training, rebuild volume rather than instantly restoring the old peak week.

## Concurrent strength and cardio

First establish priority:
- strength or hypertrophy priority
- cardio priority
- balanced general fitness
- sport priority

Then count all lower-body and high-intensity stress, including:
- heavy squats, deadlifts, lunges, and Olympic lifts
- plyometrics and sprints
- games and practices
- metcons and circuits
- hill work and loaded carries

Useful defaults:
- priority work first when sessions share a day
- easy cycling, walking, or short easy running near strength work
- separate hard lower-body sessions when practical
- avoid placing interval running before heavy lower-body work when strength quality leads
- use modality changes to reduce local interference

Concurrent training does not automatically compromise hypertrophy or maximal strength. Explosive performance and same-session quality can be more sensitive, so schedule by priority and recovery rather than myth.

## Cardio for weight or metabolic health

The programming goal is repeatable weekly activity, improved fitness, and a tolerable energy expenditure—not maximum suffering.

Useful plan characteristics:
- modalities the user can repeat
- enough easy work to accumulate time
- optional quality for fitness or preference
- strength training preserved when available
- progression by duration/frequency before punishment-level intensity

Do not guarantee scale loss. Track outcomes the user actually values, such as energy, walking tolerance, waist trend, blood-pressure trend when clinically appropriate, sleep, or fitness, without turning any single metric into a verdict.

## Limited-time programming

When the user has 10–20 minutes:
- use easy aerobic work for recovery, consistency, or base contact
- use a brief interval session only for an established user and only after warm-up is accounted for
- use relaxed speed after an easy warm-up when running coordination is the goal

Do not cram warm-up, maximal intervals, and cool-down into an unsafe fantasy session. A short easy session is a complete option.

## Cardio-specific adherence and lapse handling

Training design shapes adherence before reminders do.

Use these defaults:
- choose a modality the user can access and at least tolerate; preference and low setup friction are legitimate programming variables
- make early sessions clearly finishable so the user learns the intended effort and leaves with competence, not proof of suffering
- define one normal session and one safe lower-dose or alternate-modality version when life or recovery is uncertain
- keep the fallback faithful to the purpose; a hard-session minimum is never one all-out repetition
- use only tracking that changes the next training decision

An isolated miss usually requires no repair beyond resuming the familiar plan. When the same session is repeatedly missed, treat that as evidence about timing, dose, modality, or competing load. Change one source of friction rather than adding shame, make-up work, or more complexity.

Do not promise a fixed time to form a habit. Stable context and repetition can help, but automaticity varies widely. Compose with `behavior-followthrough` when the user needs anchors, reminders, accountability, support style, or a recurring repair loop. Fade support as the user can choose, execute, and adjust sessions independently.

## Review and next decision

Review the smallest useful set:
- completion or material change
- intended versus actual effort
- during-session symptoms or form
- later-day and next-day response
- life friction or enjoyment

Then choose one:
- repeat
- progress one lever
- hold
- regress
- substitute modality
- remove a quality session
- change mode
- hand off

Do not rebuild the entire plan after normal variation.
