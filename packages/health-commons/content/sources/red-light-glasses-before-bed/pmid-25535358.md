This source is included for **Screen-light context**.

**Findings:** Crossover study showing evening light-emitting eReader use can delay sleep/circadian physiology; supports screen-use logging but is not a glasses intervention.

**Why it matters:** Reinforces that screen exposure itself is a confounder and a separate intervention target.

**Potential experiment signals:** sleep onset latency, melatonin secretion, circadian phase, next-morning alertness

**Protocol takeaway:** Track screen use; do not add a new screen curfew at the same time as glasses.
