This source is included for **Adjacent pregnancy sleep RCT**.

**Findings:** In a related third-trimester pregnancy trial, full blue-blocking glasses did not significantly improve primary sleep outcomes versus partial blue blockers. The control lenses also blocked some blue light, which may have reduced contrast between groups. This is an adjacent null/mixed sleep result, not a general adult protocol proof.

**Why it matters:** Useful contradiction: a pregnancy sleep trial did not show statistically significant effects on primary sleep outcomes.

**Potential experiment signals:** total sleep time, sleep efficiency, mid-point of sleep, pregnancy sleep outcomes

**Protocol takeaway:** Pregnancy is an adjacent supervised variant; do not use this as a general adult protocol proof.
