**Findings:** Translational mouse plus clinical study using blue-light shield eyeglasses for one month; useful context for circadian-metabolic hypotheses, not a sleep-glasses efficacy source. Shows broader circadian hypotheses but is not a clean bedtime sleep-protocol trial.

**Why it matters:** Shows broader circadian hypotheses but is not a clean bedtime sleep-protocol trial.

**Potential experiment signals:** fasting glucose, insulin resistance, circadian rhythm, sleep quality

**Protocol takeaway:** Do not add metabolic claims to the red-light-glasses sleep protocol.
