This source is included for **Athlete pilot**.

**Findings:** Recreational athletes reported shorter sleep-onset latency, better sleep quality, and higher morning alertness with evening amber lenses. Actigraphy did not show significant differences between lens conditions. This makes subjective sleep a valid signal while keeping objective expectations modest.

**Why it matters:** Useful supporting trial for the common pattern where subjective sleep changes are clearer than objective actigraphy shifts.

**Potential experiment signals:** subjective sleep onset latency, actigraphy, sleep diary, morning alertness

**Protocol takeaway:** Helps treat subjective improvement as signal while keeping objective expectations modest.

**Claim use:** `supports-protocol`. Use this as supporting context for signal selection, not as a stand-alone reason to overclaim objective benefit.
