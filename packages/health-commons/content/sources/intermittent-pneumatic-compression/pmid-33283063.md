This source is included for **Prolonged standing/sitting and workday leg swelling sibling variant**.

**Findings:** The review searched PubMed from 2008 to 2018 using Occupational Leg Swelling, identified 23 articles, and selected five prospective/observational/experimental retrospective articles. It states that prolonged orthostatism is a risk factor and that compression stockings reduced occupational edema in the included evidence base.

**Why it matters:** It provides review-level context while warning that the occupational-edema literature is limited.
