This source is included for **same_mechanism_context**.

**Findings:** Nocturnal HRV reproducibility was parameter and sleep-stage dependent: heart rate was reproducible across sleep stages, HF power was reproducible in SWS, and LF/LF-HF reproducibility was poor.

**Why it matters:** It warns that nocturnal HRV endpoints can be sleep-stage and parameter dependent, which matters when interpreting wearable HRV changes during caffeine curfews.

**Potential experiment signals:** HRV RMSSD/HF power; Resting heart rate during sleep; Deep sleep / SWS context.

**Protocol takeaway:** Use as measurement context; it does not test caffeine.

**Claim use:** `context-only`.
