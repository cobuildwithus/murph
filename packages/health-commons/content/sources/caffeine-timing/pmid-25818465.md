This source is included for **caffeine_source_dose_audit**.

**Findings:** This methods study compared brand-specific and category-specific beverage caffeine values and concluded that brand-specific data can improve exposure estimates for some categories and age groups, while aggregate values can still provide reasonable estimates in some older datasets.

**Why it matters:** Protocol dose logs should be as specific as feasible without implying precision that category estimates cannot support.

**Potential experiment signals:** daily caffeine dose, source fidelity, brand-specific caffeine estimate.

**Protocol takeaway:** Prefer brand-specific caffeine values when available; use category-level estimates transparently when brand data are unavailable.

**Claim use:** `supports-protocol`.
