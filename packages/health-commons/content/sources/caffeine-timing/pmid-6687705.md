This source is included for **pharmacology_individual_differences**.

**Findings:** Urinary caffeine metabolites differed widely among healthy participants, providing foundational evidence of between-person variability in caffeine metabolism.

**Why it matters:** It supports the core premise that caffeine metabolism is not uniform, so curfew response may vary even with similar dose/timing.

**Potential experiment signals:** caffeine dose log, sleep-onset latency, sleep efficiency.

**Protocol takeaway:** Use as foundational same-mechanism context for variable caffeine persistence.

**Claim use:** `supports-protocol`.
