This source is included for **pharmacology_individual_differences**.

**Findings:** Smokers had shorter caffeine half-life and higher caffeine clearance than nonsmokers in this small study, indicating smoking status can materially alter residual caffeine exposure.

**Why it matters:** Smoking can shorten caffeine half-life, which changes how strict an 8-hour rule needs to be and can confound sleep-response comparisons.

**Potential experiment signals:** caffeine cutoff adherence, sleep-onset latency, sleep efficiency.

**Protocol takeaway:** Use as pharmacokinetic modifier evidence; record smoking/nicotine status rather than assuming the same caffeine persistence for everyone.

**Claim use:** `supports-protocol`.
