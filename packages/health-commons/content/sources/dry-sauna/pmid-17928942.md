This source is included for **Core-temperature threshold mechanisms and heat-stress biology**.

**Findings:** The source reports no significant intracellular HSP70 increase at either post-exposure time point after active or passive hyperthermia, despite reaching the target core temperature; passive heating reached 39 °C faster and the response appeared individual-specific.

**Why it matters:** Tests whether simply reaching an internal-temperature target is enough to produce a measurable HSP70 response; the small null result is a guardrail for any 102.4 °F / 39.1 °C protocol threshold claim.

**Potential experiment signals:** core body temperature, heat-shock protein 70, session duration to temperature target, post-session recovery window.

**Protocol takeaway:** Use only as same-mechanism context: a 39 °C core-temperature target did not reliably translate into PBMC HSP70 activation in this small study, so it should not be promoted as direct evidence that the Bryan Johnson Sauna protocol raises HSP70.

**Claim use:** `context-only`.
