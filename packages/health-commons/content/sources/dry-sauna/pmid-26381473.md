This source is included for **Safety, heat illness, medications, pregnancy, alcohol, older-adult risk**.

**Findings:** The position statement provides best-practice recommendations for preventing, recognizing, and treating exertional heat illnesses; it supports using clear symptom stop rules and rapid cooling/medical escalation for heat-stress experiments.

**Why it matters:** It gives conservative heat-illness escalation logic for any protocol that deliberately adds heat load after workouts.

**Potential experiment signals:** core temperature if available, dizziness or confusion, hydration status, resting heart rate, symptom stop rules.

**Protocol takeaway:** Use for heat-illness red flags and emergency response boundaries, not as evidence that sauna improves fitness or biomarkers.

**Claim use:** `safety-only`.
