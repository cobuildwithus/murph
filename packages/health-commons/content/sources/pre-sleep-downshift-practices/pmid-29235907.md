This source is included for **measurement_endpoints_and_wearables**.

**Findings:** Fitbit Charge 2 validation provides device-specific context for sleep/wake and staging estimates, but a single-device PSG study should not be generalized to all current consumer wearables or used as protocol efficacy evidence.

**Why it matters:** Useful because Fitbit devices are common in community tracking and this model appears in Fitbit meta-analysis tables.

**Potential experiment signals:** wearable-caveats, sleep-efficiency, total-sleep-time, wake-after-sleep-onset, sleep-onset-latency, sleep-staging.

**Protocol takeaway:** If a user tracks with Fitbit, report device model and treat stage estimates as approximate context only.

**Claim use:** `context-only`.
