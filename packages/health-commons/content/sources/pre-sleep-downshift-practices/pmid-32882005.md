This source is included for **guidelines_and_comparator_context**.

**Findings:** This framework provides step-by-step guidance and open-source code for evaluating sleep-tracker performance, including standard actigraphy and consumer devices, against reference standards. It supports caution when interpreting wearable-derived endpoints in the meditation protocol.

**Why it matters:** It defines how to evaluate device performance before trusting wearable-derived endpoints.

**Potential experiment signals:** device agreement, epoch-level performance, sleep-onset latency, sleep efficiency, sleep staging.

**Protocol takeaway:** Use as methods context when selecting or interpreting wearable data; do not treat any tracker as validated by default.

**Claim use:** `context-only`.
