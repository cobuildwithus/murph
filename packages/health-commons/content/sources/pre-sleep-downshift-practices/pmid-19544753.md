This source is included for **measurement_endpoints_and_wearables**.

**Findings:** Actigraphy-derived SOL, TST, WASO, sleep efficiency, awakenings, and motor activity can separate some insomnia and normal-sleeper profiles, but these metrics are indirect activity-based estimates rather than definitive sleep physiology.

**Why it matters:** Useful for defining which actigraphy-derived parameters might be tracked, while keeping a boundary between endpoint classification and protocol efficacy.

**Potential experiment signals:** sleep-onset-latency, sleep-efficiency, total-sleep-time, wake-after-sleep-onset, number-of-awakenings.

**Protocol takeaway:** Use SOL, TST, WASO, and sleep efficiency as descriptive signals only; avoid saying silent meditation treats insomnia based on actigraphy classification papers.

**Claim use:** `context-only`.
