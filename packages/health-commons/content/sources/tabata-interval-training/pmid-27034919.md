This source is included for **safety_msk_rhabdo_heat_respiratory**.

**Findings:** The 20/10 sprint condition produced acute cytokine increases, with return toward baseline by 24 hours, and no clear 24-hour insulin-sensitivity advantage. It is acute safety-boundary evidence only.

**Why it matters:** It provides direct 20/10 work-rest timing but only for acute sprint physiology and safety-boundary interpretation.

**Potential experiment signals:** IL-6, IL-10, TNF-alpha, 24-hour insulin sensitivity, perceived recovery.

**Protocol takeaway:** A single hard 20/10 sprint session can create acute inflammatory responses; avoid promising same-day metabolic benefit.

**Claim use:** `safety-only`.
