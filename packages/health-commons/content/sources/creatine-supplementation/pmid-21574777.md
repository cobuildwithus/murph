This source is included for **renal_safety_labs**.

**Findings:** Available excerpts report no significant group-by-time change in measured GFR after 12 weeks.

**Adverse events / safety notes:** Adds female/older-adult boundary evidence using measured GFR rather than serum creatinine alone.

**Limitations:** Small sample; Postmenopausal women only; Short duration

**Population mismatch:** Clinical/age-sex subgroup; not CKD evidence.

**Why it matters:** Important sex- and age-diverse trial using measured GFR rather than serum creatinine alone.

**Potential experiment signals:** 51Cr-EDTA measured GFR, serum creatinine, renal function

**Protocol takeaway:** Supports use of measured GFR/cystatin C context when serum creatinine is ambiguous.

**Claim use:** `safety-only`.
