**Findings:**
- The review addresses creatine supplementation in pediatric and adolescent athletes.
- It is included to preserve safety and population-boundary language for minors.
- The source should not be used to promote routine unsupervised adult-protocol dosing in youth.

**Why it matters:**
Youth athlete use is common enough to require explicit boundary language.

- population / pediatric adolescent athlete
- safety / youth athlete

- ethics / supervision

**Protocol takeaway:**
Use for youth athlete caution, not adult default dosing claims.

**Population mismatch / boundary:**
Pediatric/adolescent athletes outside default adult protocol.

**Limitations:**
- Review-level evidence.
- Not a controlled trial.
- Long-term data in healthy youth athletes remain limited.
