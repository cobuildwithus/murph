This source is included for **safety_tolerability_adverse_events**.

**Findings:**
- The review summarizes experimental studies suggesting creatine might affect fetal and neonatal morbidity/mortality in high-risk pregnancy contexts.
- This source is included to quarantine pregnancy claims from the default healthy-adult protocol.
- It does not provide direct evidence for routine unsupervised creatine monohydrate use during pregnancy.

**Why it matters:**
Pregnancy is a critical safety boundary for user-facing supplementation protocols.

**Potential experiment signals:**
- population / pregnancy
- population / fetal neonatal
- safety / pregnancy boundary
- outcome / morbidity mortality preclinical

**Protocol takeaway:**
Use to support pregnancy caution and referral/supervision boundaries rather than protocol promotion.

**Population mismatch / boundary:**
Pregnancy/fetal/neonatal populations are outside the default protocol population.

**Limitations:**
- Narrative review with substantial experimental/preclinical emphasis.
- High-risk pregnancy context differs from default adult supplementation.
- Not a protocol efficacy source.

**Claim use:** `safety-only`.
