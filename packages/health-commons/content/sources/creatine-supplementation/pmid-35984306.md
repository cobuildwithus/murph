This source is included for **population_boundary_adjacent_claims**.

## Quick read

- **Source type:** Systematic review and meta-analysis of memory RCTs (2023).
- **People studied or addressed:** Healthy individuals in memory-focused randomized controlled trials.
- **Intervention/exposure:** Creatine supplementation; dosing and duration varied across included RCTs.
- **Comparator/control:** Placebo in included RCTs.
- **Duration/follow-up:** Varied across included memory RCTs.
- **Role in Murph:** context-only / adjacent_variant.

## Findings

**Findings:** This meta-analysis included 8 RCTs and 225 healthy individuals and reported improved memory versus placebo (SMD 0.29, 95% CI 0.04 to 0.53), with more robust effects described in older adults [source_artifact:pmid-35984306].

## Why it matters

Memory is one of the more frequently overextended adjacent claims; this source keeps the effect size and scope explicit. [source_artifact:pmid-35984306]

## Potential experiment signals

Optional memory tasks may be exploratory, but the result should not be used for strength, hypertrophy, repeated-sprint, or body-composition claims [source_artifact:pmid-35984306].

## Protocol takeaway

Do not promote memory effects into the default creatine-monohydrate protocol; cite only in an adjacent cognition section or variant. [source_artifact:pmid-35984306]

## Key limitations and population mismatch

- Memory-only synthesis [source_artifact:pmid-35984306]
- Small included evidence base [source_artifact:pmid-35984306]
- Does not test gym-performance or body-composition outcomes [source_artifact:pmid-35984306]
- Subgroup signals in older adults should not be generalized [source_artifact:pmid-35984306]
- Population mismatch: Healthy cognition/memory evidence is adjacent to, not a direct source for, the default gym protocol. [source_artifact:pmid-35984306]

**Claim use:** `context-only`.
