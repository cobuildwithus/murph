This source is included for **timing_coingestion**.

**Findings:** [source_artifact:pmid-11147785] reported creatine-related changes in GLUT4/glycogen context after immobilization and rehabilitation. Because the setting involves disuse and rehabilitation, this is context-only same-mechanism evidence for the creatine monohydrate protocol.

**Why it matters:** It prevents mechanistic GLUT4 findings from being misapplied as direct protocol claims.

**Potential experiment signals:** Training interruption, rehabilitation status, body mass, and recovery context.

**Protocol takeaway:** Use only as same-mechanism context for creatine and glucose/glycogen pathways, not as an implementation rule.

**Limitations / boundary notes:** Population mismatch; mechanistic endpoints; rehabilitation context; not a timing/co-ingestion intervention in healthy active users.

**Claim use:** `context-only`.
