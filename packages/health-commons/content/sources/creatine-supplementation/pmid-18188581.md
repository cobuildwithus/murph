This source is included for **renal_safety_labs**.

**Findings:** Available excerpts report no within- or between-group renal-function impairment; decrease in cystatin C was interpreted as no renal dysfunction from high-dose creatine over 3 months.

**Adverse events / safety notes:** Stronger direct renal-safety evidence because cystatin C was used instead of relying only on serum creatinine.

**Limitations:** Small sample; Healthy young men only; Exercise training co-intervention

**Population mismatch:** Healthy males under training; not CKD or women.

**Why it matters:** Core healthy-adult RCT with cystatin C and direct kidney-function assessment.

**Potential experiment signals:** cystatin C, serum creatinine, measured/estimated renal function, adverse events

**Protocol takeaway:** Supports using cystatin C or measured GFR when creatinine-based eGFR is ambiguous.

**Claim use:** `safety-only`.
