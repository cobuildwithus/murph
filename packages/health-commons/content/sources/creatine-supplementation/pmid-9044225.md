This source is included for **repeated_sprint_power_trials**.

**Findings:** Accessible abstract summaries reported no increase in resting muscle phosphocreatine and no performance effect in a single short maximal cycling task.

**Population and intervention:** Healthy adults performing maximal cycle ergometry; Oral creatine supplementation before maximal cycle ergometry. Comparator: Placebo/control condition. Duration/follow-up: 3 days of oral creatine supplementation in accessible abstract summaries.

**Endpoints:** muscle phosphocreatine, maximal cycle ergometry power output.

**Safety notes:** No adverse-event extraction was available from the accessible record for this batch. 

**Limitations:** Sample size and full protocol details not extracted. Single maximal cycling task differs from repeated-sprint protocols.

**Population mismatch:** Lab cycling task; not a sport-field population.

**Why it matters:** Important null physiology/performance source for the power-output boundary.

**Potential experiment signals:** muscle phosphocreatine, maximal cycle ergometry power output.

**Protocol takeaway:** Short loading may not improve single maximal cycling performance.

**Murph takeaway:** Track task type and loading duration when interpreting response.

**Claim use:** `supports-protocol`. Directness: `direct_protocol`. Result boundary: `no_clear_advantage`.
