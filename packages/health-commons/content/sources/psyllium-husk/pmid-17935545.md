This source is included for **Adjacent variants, soluble-fiber comparators, and population mismatch**.

**Findings:** This randomized study evaluated viscous fiber combined with lovastatin in normal human subjects, making it relevant only as medication-combination and population-mismatch context for the psyllium cholesterol protocol.

**Why it matters:** Normal-volunteer statin-adjunct results should not be used as direct support for a cholesterol-lowering protocol in adults with elevated LDL-C.

**Potential experiment signals:** serum lipids.

**Protocol takeaway:** Use as adjacent pharmacologic/fiber-combination context only.

**Claim use:** `context-only`.
