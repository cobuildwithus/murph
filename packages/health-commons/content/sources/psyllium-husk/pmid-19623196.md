This source is included for **Direct protocol trials, dose, timing, formulation, and subgroup evidence**.

**Findings:** In 40 type 2 diabetic patients, psyllium added to dietary measures did not show a clear postprandial lipoprotein advantage over diet alone in accessible snippets, although triglyceride improvement was suggested.

**Why it matters:** Provides mixed diabetes/lipoprotein context and should not be used as a primary LDL-lowering claim.

**Potential experiment signals:** postprandial lipoproteins, triglycerides, BMI, waist circumference, HbA1c, fasting glucose.

**Protocol takeaway:** Provides mixed diabetes/lipoprotein context and should not be used as a primary LDL-lowering claim.

**Claim use:** `context-only`.

**Extraction caveat:** Sequential design and diabetes-drug context create protocol mismatch.
