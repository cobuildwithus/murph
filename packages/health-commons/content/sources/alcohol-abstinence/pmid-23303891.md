This source is included for **Alcohol-reduction comparator trials, digital interventions, and liver-focused protocols**.

**Findings:**
- `finding:pmid-23303891-no-clear-added-benefit-intensive` — SIPS found improvement across groups but did not show a clear advantage for more intensive brief intervention formats over the minimal leaflet/feedback condition in intention-to-treat comparisons.
- `finding:pmid-23303891-counselling-implementation-limited` — Implementation was imperfect: extracted summaries report that only about 57% of participants assigned to lifestyle counselling attended, highlighting adherence limits for more intensive comparator arms.

**Why it matters:** It tests active alcohol-reduction comparators and implementation intensity in primary care, clarifying that more intensive brief counselling is not automatically better.

**Potential experiment signals:** AUDIT hazardous/harmful drinking status, alcohol consumption, brief-intervention delivery, counselling attendance.

**Protocol takeaway:** Use as adjacent comparator evidence: brief advice/leaflet feedback can be a meaningful comparator, but the trial does not establish abstinence-challenge effects.

**Claim use:** `context-only`.

**Limitations and population mismatch:** Brief reduction intervention rather than abstinence; primary-care screening population; more intensive counselling uptake was incomplete; outcome mostly self-report; no alcohol-free variant.
