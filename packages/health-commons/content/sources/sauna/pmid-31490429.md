This source is included for **Intervention design / reality checks**.

**Findings:** This crossover study tested different exercise loads followed by sauna. The main finding is that pre-sauna training load changes neuromuscular and hormonal responses, so sauna effects are not isolated when paired with workouts.

**Why it matters:** Shows that what happens before the sauna session changes the response, which matters for protocol standardization.

**Potential experiment signals:** Training load, session timing, soreness, perceived recovery, next-day readiness

**Protocol takeaway:** Fix the exercise-to-sauna timing window if sauna is used as an adjunct, otherwise the signal will be noisy.
