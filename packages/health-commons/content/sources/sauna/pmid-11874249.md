This source is included for **sweat and detox-claim caveats**.

**Findings:** Dry-sauna sweat-composition study used to add mineral-loss and sweat-measurement context without overclaiming detox or microplastic clearance. Adds direct sauna-sweat composition data and supports hydration/mineral caution, but it is not evidence that sauna clears microplastics or broad toxin burden.

**Why it matters:** It shows sauna sweat contains measurable minerals and trace elements, which is useful for hydration context but not sufficient for detox claims.

**Potential Murph endpoints/context:** hydration context, electrolyte context, sweat-loss context

**Protocol takeaway:** High-burden sauna protocols should log hydration and avoid promising toxin or microplastic clearance.
