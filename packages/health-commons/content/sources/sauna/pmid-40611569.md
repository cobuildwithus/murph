This source is included for **Intervention design / reality checks**.

**Findings:** This multi-arm randomized trial found that regular post-exercise sauna bathing did not improve HRV. The main finding is important null evidence for a common wearable expectation.

**Why it matters:** Newest null HRV trial

**Potential experiment signals:** HRV

**Protocol takeaway:** Important for signal uncertainty and expectation-setting.

This is one of the most important expectation-setting papers on the page because it shows a null HRV result in a modern repeated-sauna design.
