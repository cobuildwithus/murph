This source is included for **Intervention design / reality checks**.

**Findings:** This crossover study tested post-exercise sauna bathing on swim-performance recovery. The main finding is that training-adjacent sauna should be judged partly by next-session performance, not just morning wearable scores.

**Why it matters:** Useful for sauna-around-training experiments because it pushes outcome selection toward next-session performance rather than only morning recovery scores.

**Potential experiment signals:** Overnight HRV, RHR, sleep, soreness, next-session performance, training load

**Protocol takeaway:** When sauna is paired with training, measure the next workout outcome as well as wearable recovery markers.
