This source is included for **Graded windows and adjacent TRE variants**.

**Findings:** The TEA TIME protocol directly uses an 18:6 TRE schedule in adults with type 2 diabetes, comparing TRE with standard lifestyle recommendations over 52 weeks. This article is a protocol and does not report completed efficacy results or adverse-event rates; it should be used only for design, endpoint, and safety-boundary context.

**Why it matters:** Provides direct 18:6 protocol structure in a clinical T2D population, including a 14:00–20:00 eating window and 1-year endpoint planning.

**Potential experiment signals:** beta-cell function, insulin resistance, glycemic control, body weight, adherence, adverse events.

**Protocol takeaway:** Use for safety-screening and endpoint planning in diabetes contexts; do not cite it as efficacy evidence because it is a study protocol.

**Claim use:** `supports-protocol`.
