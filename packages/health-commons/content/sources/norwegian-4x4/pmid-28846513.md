This source is included for **Adjacent variants to split**.

**Why it matters:** Low-volume 1x4 HIIT evidence that should not be treated as the same as standard 4x4.

**Findings:** The trial found that low-volume HIIT could improve metabolic-syndrome severity. Its protocol was a lower-volume variant rather than classic four-by-four-minute intervals. The finding is useful cardiometabolic context but should stay separate from Norwegian 4x4 dosing.

**Protocol takeaway:** Use this source only within its `claimUse: context-only` boundary. Do not use safety-only, mixed clinical, or adjacent-variant evidence as direct support for a general unsupervised self-experiment claim.
