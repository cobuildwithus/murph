This source is included for **home_low_burden_trials**.

**Findings:** A home hip-flexor stretching RCT found active and passive approaches both increased hip extension ROM in a clinical young-adult sample. Active and passive hip-flexor stretching were reported as similarly effective for increasing hip extension ROM in the clinical sample.

**Why it matters:** It supports home feasibility while preventing clinical-impairment evidence from being overpromoted into the main protocol promise.

**Potential experiment signals:** hip extension ROM, symptoms, adherence.

**Protocol takeaway:** Home static-style stretching can be used in clinical ROM work, but Murph claims should distinguish healthy-adult flexibility from rehab contexts.

**Claim use:** `context-only`.
