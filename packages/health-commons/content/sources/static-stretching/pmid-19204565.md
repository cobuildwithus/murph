This source is included for **home_low_burden_trials**.

**Findings:** A multi-technique hamstring RCT included static/passive stretching but the available extraction inputs do not isolate a clean static-stretch effect estimate. Available extraction inputs state that hamstring flexibility can improve with multiple stretching approaches; technique-specific effect estimates were not extracted.

**Why it matters:** It prevents overclaiming from comparator trials where the exact static-stretch contribution is not cleanly extractable.

**Potential experiment signals:** hamstring ROM, technique boundary.

**Protocol takeaway:** Do not cite this as a primary static-stretch efficacy source unless the static arm is extracted in more detail.

**Claim use:** `context-only`.
