This source is included for **home_low_burden_trials**.

**Findings:** A classic frequency trial suggests 30 seconds once daily can be sufficient for hamstring ROM, with no clear added gain from longer or more frequent daily stretching. Available extraction notes report no differences among stretching groups; 30 seconds once daily was effective, and increasing duration to 60 seconds or frequency to three times daily did not add clear benefit.

**Why it matters:** It directly supports the low-burden design principle: more stretch time is not always better.

**Potential experiment signals:** hamstring ROM, daily frequency, session duration.

**Protocol takeaway:** Start with a realistic low-burden dose before adding frequency or duration.

**Claim use:** `supports-protocol`.
