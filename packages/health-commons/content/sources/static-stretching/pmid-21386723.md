This source is included for **hamstring_sit_reach**.

**Findings:**
Static stretching improved single-session hamstring length, but PNF was superior in this therapist-applied comparison. Endpoint: Passive knee-extension hamstring length. Effect/direction: Static stretching and PNF both increased hamstring length versus control; PNF produced a larger gain than static stretching in accessible reporting.

**Why it matters:** Preserves the possibility that PNF can outperform static stretching acutely, preventing overstated static superiority.

**Potential experiment signals:**
- Passive knee-extension ROM
- Immediate response to one session

**Protocol takeaway:** Use as adjacent comparator evidence only; a PNF advantage in a therapist-applied single session does not invalidate static stretching as a simpler home protocol.

**Claim use:** `context-only`.

**Extraction notes:**
- Study design: Randomized single-session comparison of therapist-applied static stretching, PNF, and control.
- Population: 45 healthy subjects aged 21-35 years.
- Intervention/exposure: Therapist-applied static hamstring stretch for 30 seconds.
- Comparator/control: PNF stretch and control group.
- Duration/follow-up: Single session.
- Endpoints: Passive knee-extension hamstring length
- Adverse events or safety notes: Adverse events were not reported in accessible abstract/metadata.
- Limitations: Single-session therapist-applied protocol; PNF comparator; not home self-directed.
- Population mismatch: Adjacent because intervention delivery is therapist-applied and comparator-focused.
