This source is included for **mechanisms_upper_body_general_primary**.

**Findings:** No significant changes were found in flexibility or kicking variables after the static-stretching warm-up condition compared with the non-stretch warm-up.

**Why it matters:** This preserves a null acute result and prevents overgeneralizing static stretching as immediately performance-enhancing.

**Potential experiment signals:**

- Thomas test flexibility
- kicking leg ROM
- foot speed

**Protocol takeaway:** Do not promise acute sport-performance benefits from static stretching.

**Claim use:** `context-only`.
