This source is included for **home_low_burden_trials**.

**Findings:** In older women, Pilates appeared to outperform static stretching for some flexibility segments in the available extraction notes. Available extraction notes indicate Pilates may have been more effective than static stretching for some body segments.

**Why it matters:** It is a useful boundary source so static stretching is not oversold against more complex flexibility modalities.

**Potential experiment signals:** segmental flexibility, variant separation.

**Protocol takeaway:** Do not claim static stretching is always superior to Pilates or other flexibility methods.

**Claim use:** `context-only`.
