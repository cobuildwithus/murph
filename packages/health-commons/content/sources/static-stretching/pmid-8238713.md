**Findings:** The prevention program did not significantly reduce running injuries; reported injury rates were 4.9 versus 5.5 per 1000 running hours in the extracted summary. Source key: `source_artifact:pmid-8238713`.

**Adverse events or safety notes:** No stretching-specific adverse events were extracted.

**Limitations and population mismatch:** Running injury-prevention bundle, not static-stretch-only home protocol. Limitations: Bundled intervention prevents isolating stretching.; Male recreational runners and injury-prevention objective differ from home flexibility..

**Why it matters:** It provides an important null adjacent injury-prevention result.

**Potential experiment signals:** running injury incidence, injury rate per 1000 running hours, knowledge and attitude about prevention.

**Protocol takeaway:** Do not present static stretching as a proven running-injury prevention tool.
