This source is included for **home_low_burden_trials**.

**Findings:** An eight-week home hamstring-stretching RCT found ROM improvements versus control, with no clear superiority between two stretching-program structures. Hip flexion and knee extension ROM increased more in stretching groups than controls in the available abstract-level extraction; differences between the two stretching programs were not clearly significant.

**Why it matters:** This is among the most direct home-based flexibility evidence for a low-burden static-stretching protocol.

**Potential experiment signals:** hip flexion ROM, knee extension ROM, adherence, session burden.

**Protocol takeaway:** Home hamstring static stretching can support ROM gains, but exact program structure should not be overclaimed from the extracted data.

**Claim use:** `supports-protocol`.
