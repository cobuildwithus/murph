This source is included for **home_low_burden_trials**.

**Findings:** Under matched parameters, static stretching appeared more effective than the compared non-static techniques in a small young-adult hamstring trial. Available extraction notes indicate the static-stretching arm improved hamstring flexibility, while active self-stretching and PNF-style arms did not clearly outperform control under the same parameters.

**Why it matters:** It helps keep protocol claims specific to static stretching rather than blending static stretching, PNF, and active mobility methods.

**Potential experiment signals:** hamstring ROM, technique boundary.

**Protocol takeaway:** Keep the protocol definition narrow: sustained static holds, not PNF or active mobility unless separately labeled.

**Claim use:** `context-only`.
