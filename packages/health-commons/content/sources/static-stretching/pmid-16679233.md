**Findings:** All three pectoralis minor stretches differed significantly, and the unilateral self-stretch produced the greatest measured length change.

**Why it matters:** This is one of the batch’s more protocol-relevant upper-body sources because it directly compares a self-administered static stretch position.

**Potential experiment signals:**

- pectoralis minor length change
- shoulder/scapular stretch position

**Protocol takeaway:** A unilateral self-stretch can be cited as an upper-body stretch-position option, but only for acute pectoralis minor length change rather than long-term flexibility outcomes.
