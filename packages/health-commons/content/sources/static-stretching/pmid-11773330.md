This source is included for **mechanisms_upper_body_general_primary**.

**Findings:** Resistance training increased tendon stiffness-related outcomes; the side receiving added static stretching showed changes in viscosity/hysteresis rather than a clear standalone elasticity effect.

**Why it matters:** It is relevant to tissue-mechanics context but adjacent to the target because stretching was combined with resistance training.

**Potential experiment signals:**

- tendon stiffness
- hysteresis
- viscosity
- plantar-flexor training

**Protocol takeaway:** Use only as adjacent tendon-mechanics context, not as standalone static-stretching efficacy evidence.

**Claim use:** `context-only`.
