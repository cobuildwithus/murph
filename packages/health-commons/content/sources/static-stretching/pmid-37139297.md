This source is included for **home_low_burden_trials**.

**Findings:** A six-week self-performed daily high-volume static-stretching study reported flexibility and strength changes without an acute CK increase in available notes. Available extraction notes report significant increases in maximum strength and flexibility; acute creatine kinase did not increase.

**Why it matters:** It is home-translatable but highlights how dose can drift far beyond a low-burden Murph routine.

**Potential experiment signals:** flexibility, strength, muscle soreness or CK safety, time burden.

**Protocol takeaway:** High-volume stretching studies should not define the default low-burden dose.

**Claim use:** `context-only`.
