This source is included for **ankle_calf_dorsiflexion**.

**Findings:** In 36 recruited volunteers, 28 completed a 3-week home program. Weight-bearing and non-weight-bearing 5 x 30-second twice-daily stretches both increased dorsiflexion measures, with no significant between-group difference.

**Why it matters:** This source is directly relevant to at-home calf-stretch setup choices and supports flexible implementation when users cannot do one version comfortably.

**Potential experiment signals:** Weight-bearing dorsiflexion; Non-weight-bearing dorsiflexion; Stretch position choice.

**Protocol takeaway:** Either weight-bearing or non-weight-bearing calf stretching can be used as a home-feasible variant; do not claim one is superior based on this trial.

**Limitations:** 28 of 36 recruited participants completed. No no-stretch comparator was extracted for this source. Restricted-dorsiflexion sample.

**Population mismatch:** Healthy volunteers with restricted dorsiflexion; relevant but not fully general.

**Claim use:** `supports-protocol`.
