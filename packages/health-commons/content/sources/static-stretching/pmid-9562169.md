This source is included for **region_specific_remote_measurement**.

**Findings:** The study used the modified Thomas test to quantify regional flexibility in elite athletes; it was not an intervention trial.

**Why it matters:** It provides historical/region-specific measurement background without supporting modern home-stretching claims.

**Potential experiment signals:** Modified Thomas test, Hip flexor flexibility, Quadriceps flexibility, Tensor fascia latae/iliotibial band flexibility.

**Protocol takeaway:** Avoid using elite-athlete ranges as goals for general users.

**Claim use:** `context-only`.

**Extraction boundaries:**

- Population: Elite athletes from sports including tennis, basketball, rowing, and running in accessible summaries
- Intervention/exposure: Modified Thomas test assessment of iliopsoas, quadriceps, and tensor fascia latae/iliotibial band flexibility
- Comparator/control: Descriptive assessment across athlete groups
- Duration/follow-up: Cross-sectional assessment
- Adverse events or safety notes: No adverse events were extracted.
- Population mismatch: Elite athletes, not general at-home stretchers.
- Directness: Historical measurement context for modified Thomas test; not protocol efficacy evidence.

**Limitations:**

- Elite-athlete sample from 1998.
- Descriptive measurement context only.
- Athletic norms should not be applied to general home users.
