This source is included for **home_low_burden_trials**.

**Findings:** An eight-week home pectoralis static-stretching program improved shoulder flexibility in a small recreational sample. Available extraction notes report intervention gains of approximately 7.4 ± 5.6% in bench-press 1RM and 9.8 ± 5.0% in shoulder ROM, with group-by-time effects.

**Why it matters:** It directly supports home self-administration, while warning that some positive recent trials use much larger doses than a short flexibility routine.

**Potential experiment signals:** shoulder ROM, strength, adherence, time burden.

**Protocol takeaway:** Home static stretching can work, but high-volume strength-oriented stretching should remain separate from low-burden flexibility guidance.

**Claim use:** `supports-protocol`.
