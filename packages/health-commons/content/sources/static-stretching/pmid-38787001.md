This source is included for **adjacent_variants_recovery_modalities**.

**Findings:** Ten RCTs with 282 athletes were included. The overall effect indicated a moderate ROM effect for myofascial release versus active/passive control (reported ES = 0.53, 95% CI 0.18 to 0.89, p = 0.01) with high heterogeneity (I² = 77.6%). Included studies did not report adverse effects or injury.

**Why it matters:** Manual and self-myofascial-release techniques may improve ROM but are not static stretching; keep them as sibling/manual-modality evidence.

**Potential experiment signals:** joint ROM, athlete ROM, manual modality response.

**Protocol takeaway:** Use only for myofascial-release sibling scoping; do not cite as static stretching efficacy.

**Claim use:** `context-only`.
