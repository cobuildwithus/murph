This source is included for **adjacent_variants_recovery_modalities**.

**Findings:** Eighty-five studies were eligible: 72 on static stretching and 13 on foam rolling, with 204 effect sizes. Static stretching (ES = -1.006; p < 0.001) and foam rolling (ES = -0.729; p = 0.001) both increased ROM versus control, with no significant overall subgroup difference (p = 0.228). For interventions <=4 weeks, static stretching showed a significant advantage over foam rolling (p < 0.001).

**Why it matters:** High-relevance comparator review that directly separates static stretching and foam rolling training effects.

**Potential experiment signals:** joint ROM, program duration, variant separation.

**Protocol takeaway:** May be cited only for comparator boundaries; static-stretching arms still need direct static-stretch extraction before protocol claims.

**Claim use:** `context-only`.
