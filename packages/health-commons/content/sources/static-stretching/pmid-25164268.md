This source is included for **mechanisms_upper_body_general_primary**.

**Findings:** Lower-intensity protocols did not increase joint angle despite longer duration, while the highest-intensity protocol increased angle and passive peak torque; duration contributed to passive torque reduction.

**Why it matters:** This source is directly useful for dose-language boundaries in a home stretching protocol.

**Potential experiment signals:**

- stretch intensity
- stretch duration
- passive torque
- joint angle
- perceived discomfort

**Protocol takeaway:** Use moderate, tolerable stretch-intensity guidance and avoid claiming that duration alone guarantees ROM gain.

**Claim use:** `supports-protocol`.
