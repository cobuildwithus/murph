This source is included for **region_specific_remote_measurement**.

**Findings:** The study reported that the modified Thomas test was not a valid measure of hip extension unless pelvic tilt was controlled; accessible summaries report poor classification performance without pelvic control and very high variance explanation when pelvic tilt was controlled.

**Why it matters:** A home static-stretching protocol may use hip-extension or hip-flexor endpoints; this source defines a key measurement pitfall.

**Potential experiment signals:** Hip extension ROM, Pelvic tilt control, Modified Thomas test validity, Sensitivity and specificity.

**Protocol takeaway:** Any modified-Thomas-style endpoint should include pelvic-position instructions and warn users that uncontrolled pelvic tilt can create false changes.

**Claim use:** `context-only`.

**Extraction boundaries:**

- Population: Healthy college students
- Intervention/exposure: Modified Thomas test hip-extension assessment
- Comparator/control: Hip-extension interpretation with versus without pelvic tilt control
- Duration/follow-up: Single-session validity study
- Adverse events or safety notes: No adverse events were extracted.
- Population mismatch: Healthy college students, not a home-stretching population.
- Directness: High-value measurement limitation for hip-flexor outcomes; not efficacy evidence.

**Limitations:**

- Healthy student sample.
- Measurement-validity source rather than an intervention.
- Warns that uncontrolled pelvic positioning can invalidate hip-extension interpretation.
