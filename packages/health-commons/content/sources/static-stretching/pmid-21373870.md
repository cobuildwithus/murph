This source is included for **adverse_event_clinical_population_mismatch**.

**Findings:** The review emphasized that dynamic stretching generally has no negative effect or may augment subsequent performance, while static stretching can impair some acute performance outcomes when used immediately before maximal tasks. Source key: `source_artifact:pmid-21373870`.

**Adverse events or safety notes:** No adverse-event rates were extracted; performance impairment is the relevant timing boundary.

**Limitations and population mismatch:** Athletic warm-up/performance context, not direct home stretching for flexibility. Limitations: Narrative review and acute sport-performance focus.; Does not test chronic at-home flexibility outcomes..

**Why it matters:** It supports separating flexibility sessions from pre-performance warm-up choices.

**Potential experiment signals:** strength, power, speed, performance, warm-up sequencing.

**Protocol takeaway:** Avoid implying that static stretching immediately before maximal performance is always beneficial.

**Claim use:** `safety-only`. Boundary: Use for timing guidance only; do not use to judge chronic flexibility efficacy.
