This source is included for **home_low_burden_trials**.

**Findings:** Equal-dose comparison favored static over ballistic hamstring stretching in available extraction notes, with no serious complications reported. Available extraction notes report static stretching improved hamstring length more than ballistic stretching or control; ballistic improvement was smaller and not clinically meaningful.

**Why it matters:** It supports choosing sustained static holds rather than ballistic stretching in a low-risk home routine.

**Potential experiment signals:** hamstring ROM, soreness, safety.

**Protocol takeaway:** Keep the protocol static and controlled; do not blend in ballistic stretching.

**Claim use:** `context-only`.
