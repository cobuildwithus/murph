This source is included for **cardiometabolic_fitness_endpoints**.

**Findings:** A systematic review/meta-analysis of exercise interventions in healthy participants found exercise types, especially endurance and yoga, lowered resting heart rate. This is same-mechanism context for walking/fitness physiology, not Daily Step Floor evidence.

**Why it matters:** Provides mechanistic/physiologic context for resting-heart-rate changes when daily walking meaningfully increases aerobic activity.

**Potential experiment signals:** biomarker:resting-heart-rate, biomarker:estimated-vo2max.

**Protocol takeaway:** Use only as same-mechanism context for RHR; do not use as evidence that a daily step floor lowers RHR.

**Claim use:** `context-only`.

**Directness boundary:** `same_mechanism`. This source should not be promoted beyond that scope in the Daily Step Floor protocol.

**Safety/adverse events:** No adverse-event signal extracted from accessible abstract text.

**Limitations and population mismatch:** Not step-specific; broad exercise modalities and healthy-subject evidence. Population mismatch: Healthy participants and broad exercise programs differ from step-floor users.
