This source is included for **anatomy-specific sibling: neck, under-eye, or periocular evidence**.

**Findings:** The source reports a daily 16-week home-use LED schedule for neck wrinkles. Extracted summaries report significant Lemperle Wrinkle Scale, GAIS, hydration, elasticity, and density changes after treatment, with some persistence after discontinuation. Thyroid-function tests and thyroid ultrasound did not show significant changes in the extracted summaries. Source key: `source_artifact:pmid-33921839`.

**Why it matters:** It gives adjacent-anatomy evidence on neck wrinkles and thyroid-adjacent monitoring, a common safety concern for neck/chest LED devices.

**Potential experiment signals:** neck wrinkle scale, GAIS, hydration, elasticity, skin density, thyroid function tests, thyroid ultrasound.

**Protocol takeaway:** Use for safety-boundary and neck-specific context only; do not generalize to facial-mask efficacy without separating anatomy.

**Claim use:** `context-only`.
