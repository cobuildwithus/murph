This source is included for **review or consensus context for dermatology PBM**.

**Findings:** This systematic review evaluated home-based dermatology devices for safety and efficacy. It is useful for consumer-device context and safety boundaries, but it does not provide direct red/NIR photoaging efficacy evidence unless individual underlying trials are separately extracted.

**Why it matters:** Many red/NIR skin protocols use home masks or panels, so device setting and supervision context affect interpretation.

**Potential experiment signals:** home-device indication, user adherence, adverse events, device clearance status, skin-type reporting.

**Protocol takeaway:** Do not assume a home device has the same risk-benefit profile as a clinic device or a trial-grade LED array.

**Claim use:** `context-only`.
