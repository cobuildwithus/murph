This source is included for **adjacent device or combination-intervention evidence**.

**Findings:** The source title and metadata identify peri-orbital rejuvenation using radiofrequency plus LED technology. The batch extraction did not verify a sample size, wavelength dose, comparator, LED-only effect estimate, or safety details, so the source should not support red+NIR facial-mask claims. Source key: `source_artifact:pmid-19839877`.

**Why it matters:** It prevents radiofrequency-plus-LED peri-orbital findings from being over-pooled with red+NIR photobiomodulation evidence.

**Potential experiment signals:** periorbital appearance, co-intervention tracking, device attribution boundary.

**Protocol takeaway:** Do not use for efficacy claims; retain only as a combination-device boundary.

**Claim use:** `do-not-use`.
