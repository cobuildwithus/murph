This source is included for **dry_eye_treatment_prevention**.

**Findings:** Week-12 changes reported in secondary sources included tear osmolarity −19.4 vs −8.3 mOsm/L, TBUT +3.5 vs +1.2 s, OSDI −17.0 vs −5.0, omega-3 index +3.0% vs +0.2%; MMP-9 positivity reduction was also greater in omega-3.

**Why it matters:** Positive rTG trial sets up an important contrast with the later negative rTG multicenter RCT.

**Potential experiment signals:** OSDI, tear osmolarity, TBUT, MMP-9, omega-3 index.

**Protocol takeaway:** Supports formulation-specific positive context, but later large rTG trials found no clear symptom advantage, so it should not be promoted alone.

**Claim use:** `context-only`.

**Population mismatch / boundary:** Direct dry-eye treatment trial but formulation-specific and not a generalized wellness claim.

**Safety notes:** GI upset has been discussed clinically for omega-3 products, but no specific trial AE table was extracted here.

**Limitations:** Product-specific rTG formulation.; Safflower/linoleic-acid control may not be inert.; Baseline imbalances and industry context should be checked in full text before synthesis..
