This source is included for **mood_cognition**.

**Findings:** Fish-oil supplementation increased RBC omega-3 content, working-memory performance, and BOLD signal in the posterior cingulate during working-memory load. Safety note: No safety result extracted.

**Why it matters:** Connects supplementation to status and brain-activation endpoints.

**Potential experiment signals:** RBC omega-3 content, working memory performance, BOLD signal, posterior cingulate activation.

**Protocol takeaway:** Use as mechanistic context, not stand-alone efficacy evidence.

**Population mismatch:** Subjective memory impairment in older adults; adjacent to general cognition.

**Limitations:** Small neuroimaging/mechanistic-adjacent context likely; participant count not extracted.; Subjective memory impairment population does not represent general healthy users.

**Claim use:** `context-only`.
