This source is included for **inflammation_immune_markers**.

**Findings:** Both EPA and DHA lowered plasma triglycerides and changed apolipoprotein/lipoprotein ratios; DHA uniquely increased LDL-C in extracted summaries. [source_artifact:pmid-36522805]

**Why it matters:** Provides EPA-versus-DHA lipid-metabolism context for inflammatory-risk cohorts.

**Potential experiment signals:** triglycerides, LDL-C, EPA vs DHA, low-grade inflammation.

**Protocol takeaway:** Track lipid tradeoffs when using high-dose component-specific products.

**Population mismatch:** Direct oral EPA/DHA component evidence but mainly lipid-mechanism focus within an inflammation batch.

**Safety notes:** Safety/adverse events were not extracted from the article; linked registry noted non-active-phase dropouts including gout and leg cramps during placebo lead-in.

**Limitations:** Lipid metabolism source rather than primary inflammation endpoint. Small low-grade inflammation cohort. Ethyl-ester component-specific intervention differs from many mixed products.

**Claim use:** `supports-protocol`.
