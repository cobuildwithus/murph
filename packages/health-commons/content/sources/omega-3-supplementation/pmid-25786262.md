This source is included for **mood_cognition**.

**Findings:** Episodic memory outcomes in adults with mild memory complaints improved with DHA/EPA supplementation; >1 g/day DHA/EPA improved episodic memory regardless of baseline cognitive status. Semantic and working-memory changes from baseline were reported, but between-group differences were not detected. Safety note: No batch-specific safety extraction.

**Why it matters:** DHA-specific synthesis helps distinguish memory-domain claims from broader cognition claims.

**Potential experiment signals:** episodic memory, semantic memory, working memory.

**Protocol takeaway:** Use only as context for memory-specific outcomes, especially where users report mild memory complaints.

**Population mismatch:** Best fit is adults with mild memory complaints, not general healthy-adult cognition.

**Limitations:** Memory-domain focus rather than broad cognitive-function assessment.; Mild-memory-complaint enrichment limits generalization to asymptomatic adults.; Some author affiliations/industry relevance should be reviewed in a full evidence appraisal.

**Claim use:** `context-only`.
