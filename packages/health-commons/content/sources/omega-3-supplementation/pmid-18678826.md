This source is included for **mood_cognition**.

**Findings:** Plasma EPA-DHA increased substantially in active arms, but no significant differential changes were reported in cognitive domains.

**Why it matters:** Pairs adherence/status signal with null cognitive endpoints.

**Potential experiment signals:** cognitive domains, plasma EPA-DHA.

**Protocol takeaway:** Raising EPA/DHA status does not guarantee measured cognitive improvement.

**Population mismatch:** Older-adult cognition context; not mood or general performance claims.

**Limitations:** Shorter 26-week older-adult study.; Participant count not extracted during this run.

**Claim use:** `context-only`.
