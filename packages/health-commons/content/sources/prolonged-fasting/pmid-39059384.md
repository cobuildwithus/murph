This source is included for **adjacent fasting variants and terminology**.

**Findings:** The consensus defines intermittent fasting as repetitive fasting periods lasting ≤48 hours, short-term fasting as 2–3 days, and prolonged fasting as ≥4 consecutive days, which means the Murph protocol label 'Prolonged Fasting (24–72 Hours)' overlaps consensus intermittent/short-term terminology rather than consensus prolonged fasting.

**Why it matters:** Best terminology anchor for separating TRE, ADF, religious fasting, short-term fasting, and prolonged fasting in the protocol page.

**Potential experiment signals:** Fasting terminology; Protocol naming; Variant boundaries.

**Protocol takeaway:** Use as a high-priority taxonomy boundary source; protocol synthesis should explicitly label 24–72 hours as overlapping consensus short-term fasting/≤48-hour IF definitions.

**Claim use:** `context-only`.
