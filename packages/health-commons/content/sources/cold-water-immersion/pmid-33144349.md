This source is included for **Sleep, HRV, and recovery context**.

**Findings:** The consensus source supports structured sleep measurement and screening in athlete recovery contexts.; The source should not be used as efficacy evidence for cold plunge because it is not a CWI trial.

**Why it matters:** Provides authoritative sleep-measurement context for athlete recovery claims and helps define sleep endpoints responsibly.

**Potential experiment signals:** biomarker:sleep-efficiency, biomarker:sleep-onset-latency, self_report:sleep_quality, self_report:daytime_sleepiness.
