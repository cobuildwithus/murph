This source is included for **Sleep, HRV, and recovery context**.

**Findings:** The review supports HRV as a useful autonomic measurement context for cold exposure, but within diving rather than cold-plunge protocols.; Because diving adds breath control, pressure, depth, and extreme cold, the review should not be used as cold-plunge efficacy evidence.

**Why it matters:** HRV is a plausible autonomic endpoint, but diving physiology and extreme cold create safety boundaries that should not be generalized to casual plunge benefits.

**Potential experiment signals:** biomarker:hrv-rmssd, biomarker:resting-heart-rate, safety:arrhythmia.

**Protocol takeaway:** Use as HRV measurement/safety context only.

**Claim use:** `safety-only`.
