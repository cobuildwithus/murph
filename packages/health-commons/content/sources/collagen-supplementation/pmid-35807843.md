This source is included for **tendon-loading-ligament**.

**Findings:** Vitamin C is relevant to tendon recovery because it supports collagen synthesis, but it is not HCP efficacy evidence. Use to flag vitamin C co-intervention boundaries in tendon/loading trials.

**Why it matters:** It helps prevent over-attribution in collagen-plus-vitamin C protocols.

**Potential experiment signals:** tendinopathy recovery, collagen synthesis, vitamin c cointervention.

**Protocol takeaway:** Context only; separate vitamin C contribution from collagen peptides.

**Claim use:** `context-only`.
