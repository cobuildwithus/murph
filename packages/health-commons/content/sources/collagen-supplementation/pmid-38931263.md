This source is included for **skin-aging**.

**Findings:** Collagen plus vitamin C arms improved density/texture/wrinkle measures but not all skin-function endpoints, and co-ingredients limit attribution. Endpoints captured: dermis density; dermis thickness; skin viscoelasticity; skin hydration; skin roughness; wrinkle volume; wrinkle depth; adverse events.

**Why it matters:** This recent trial preserves both positive and null endpoint patterns in a co-ingredient design.

**Potential experiment signals:** dermis density, skin roughness, wrinkle morphology, hydration, elasticity, adverse events.

**Protocol takeaway:** Do not cite as collagen-only evidence; note mixed endpoints and vitamin C/HA co-ingredient boundary.

**Claim use:** `context-only`.
