Breaking Changes
- The public experiment progress-card URL encoder, decoder, encoded-length constant, and path builder are removed from `@murphai/contracts`. Private attachment media is the supported replacement.

New Features
- Publishes the current `@murphai/hosted-execution` orchestration contract required by Murph Cloud, including system-mailbox processing.

Release Policy
- This is an intentionally breaking minor release while the public package surface has no supported external compatibility commitment.
- All five public packages continue to publish at one exact shared version.
