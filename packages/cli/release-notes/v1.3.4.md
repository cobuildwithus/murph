# Murph 1.3.4

Startup mailbox reads can reuse a prefetched response when a duplicate wake is already covered. Newer or unknown work still requires a fresh read, and imported-item cursors remain authoritative.

The shared hosted-execution contract adds optional complete mailbox wake coverage. Deploy the compatible runtime consumer before orchestration producers send the hint. Older producers keep their existing behavior.

All five public packages share version 1.3.4. This release also includes the changes already merged since v1.3.3; see the [complete comparison](https://github.com/cobuildwithus/murph/compare/v1.3.3...v1.3.4).
