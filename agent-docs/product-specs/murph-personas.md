# Murph Personas

Last verified: 2026-07-20
Status: Implemented contract

## Product decision

First-visit personalization begins with one understandable archetype rather than separate technical controls. A persona is one stable canonical preference id. Code owns its prompt, default writing style, default voice, and default Humor, Push, and Detail values.

The first-visit save sends one request and produces one `member.preferences.updated` mailbox event containing:

- persona
- chosen writing style (`formal` for standard capitalization or `casual` for lowercase)
- chosen voice

Persona dial defaults are never copied into storage. Existing sparse dial overrides continue to win over the selected persona at read time.

## Catalog

Classic Murph, Navy SEAL, Stoic Philosopher, Wise Elder, Medical Detective, Longevity Scientist, Hype Coach, Zen Monk, Best Friend, Championship Coach, Science Professor, Mountain Guide, Grandma, Biohacker, and Drill Sergeant.

Every persona has five recommended existing voices and persona-specific preview copy. Preview assets use `/audio/murph-personas/<persona-id>/<voice-id>.mp3` and are generated by `scripts/generate-murph-persona-previews.mjs` through the existing ElevenLabs configuration.

## Resolution

Effective style resolves in this order for each primitive:

1. explicit saved tone, voice, or dial override
2. selected persona default
3. Classic Murph default when persona is absent or invalid

No prompt body, inferred profile, or conversation excerpt is stored. Persona prompt behavior stays code-owned in the assistant engine.

## Scope

Personal personas apply to private Murph conversations. Hosted room Murph remains independent and does not inherit a participant's private persona. Persona changes expression and emphasis, never facts, evidence standards, safety, privacy, consent, authorization, tool authority, notification cadence, or action status.

## Existing members

No backfill is required. Missing persona resolves to Classic Murph, while any existing tone, voice, Humor, Push, or Detail values remain explicit overrides. Existing members therefore keep their current behavior.
