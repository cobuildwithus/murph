# Block runner releases on provider web tool admission

A model catalog change can invalidate a reserved OpenAI tool before a regular foreground turn produces an answer. Verify the exact native request locally and in required CI. Verify the real API on the isolated candidate before member container replacement.

- Use the pinned App Server, both image catalogs and an independently stored accepted schema. Prove the historical configuration fails on GitHub and the corrected configuration passes.
- Retain the serving Luna probe. Before admitting a new production runner, require a synthetic turn from Sol and Astra. Use one model-scoped egress grant per turn, require the web namespace on the outbound request, and verify content-free receipts against the candidate manifest.
- Exercise malformed or missing receipts and the existing promotion stop path. Keep the previous member image serving if a candidate fails. The compatible Worker is activated before this phase.
- Verify local typecheck, exact-head CI, final review and the protected production deployment.
