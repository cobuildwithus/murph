# Keep failed worktree retirement recoverable

Status: completed
Created: 2026-09-06
Updated: 2026-09-06

## Goal

Make a failed non-force retirement leave its previously clean checkout retryable when only tracked files were deleted. Preserve all existing admission and ownership checks.

## Scope and protected invariants

The existing `scripts/retire-worktree` remains the sole owner. Recover only immediately after this invocation's failed removal and only from its unchanged Git index and HEAD. Never overwrite an existing file, follow a replacement parent symlink, force removal, restore missing Git metadata, or create a durable recovery ledger. Leave ambiguous or unrecoverable state untouched with a bounded diagnostic.

## Cause and approach

An exact function-seam probe reproduced partial tracked deletion, suppressed Git failure, and rejection of the next attempt as dirty. The current failure test never deletes a file. Native `git checkout-index` without force restores absent indexed paths and refuses existing files or symlink parents. Use this primitive after validating unchanged metadata, index, HEAD, branch, ownership, and absence of other changes.
