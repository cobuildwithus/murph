# Update Codex CLI to 0.143.0

## Goal

Update Murph's pinned hosted Codex CLI/runtime dependency from `0.142.5` to the current published `@openai/codex` stable `latest` dist-tag, `0.143.0`.

Success means the package manifest, lockfile, hosted runner base image pin, Cloudflare CI/deploy image contracts, tests, and docs all agree on `0.143.0`, with focused verification proving the static container contract.

## Scope

- `@murphai/assistant-engine` dependency on `@openai/codex`.
- Hosted runner base Dockerfile `CODEX_CLI_VERSION`.
- Hosted runner default base image tag.
- CI/deploy workflow references to the stable base image tag.
- Cloudflare base-image contract helper, focused tests, and deployment docs.

## Out Of Scope

- Codex prompt behavior, model catalog policy, app-server protocol changes, or hosted execution semantics.
- Switching to alpha prereleases.
- Changing Cloudflare deployment topology.

## Decisions

- Use `0.143.0`, the current npm `latest` dist-tag. The requested `1.4.3` is not a published `@openai/codex` version.
- Keep the existing stable-base-image naming convention and update only the version suffix.
- Do not add new compatibility layers or runtime abstractions for this version bump.

## Risks

- Hosted runner deploys require the matching `node24.14.1-codex0.143.0` base image to be built/pushed before app-layer builds that rely on the default tag.
- Active warm Cloudflare runner containers may continue running the previous Codex binary until replaced.
