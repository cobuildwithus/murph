# Completed Plan Snapshots

Files in this directory are immutable, non-operative historical snapshots.
They record what was believed when a task closed and may contain assumptions
superseded by later review or implementation.

Do not use a completed plan as current implementation, deployment, rollback,
or incident-response guidance. Follow the live owner documents indexed in
`agent-docs/index.md`; when a snapshot conflicts with a live owner document,
the live owner document prevails and the snapshot remains unchanged.
