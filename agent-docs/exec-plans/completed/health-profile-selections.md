# Health profile selections

Extend the existing game profile and Health wins audience. Seal milestone cards at selection time, bind live streaks to eligible games, and derive shared progress only from authorized board projections. Keep each selection list bounded to three and serialize replacements against the owner's profile. Check migration constraints, revocation paths, version checks and compatibility with existing clients.

## Outcome

The profile accepts covers, ordered versioned pins, and up to three working-on factors. Partner progress uses existing board grants, with a separate permission for sleep timing. Mutual game streaks use game rules and viewer-qualified identities. Settings exports retained profile choices and outgoing cheers. Member deletion removes the three new tables' records through foreign keys.

The full migration history applied to a fresh local PostgreSQL database. Ten focused test files passed with all 280 cases, including consent revocation, stale selection revisions, media authorization, Settings export after consent withdrawal, and account deletion. Web typechecking and the raw health log, documentation drift, and complexity checks passed.

The sleep-timing reader matches the check-in lane's core projection. The You engine needs to supply a current, versioned age summary that is safe for profile publication. The existing owner-only age helper supplies no selection revision. The profile skips age until this dependency is available. The private weekly view can use the exported working-on reader when the lanes are integrated.
