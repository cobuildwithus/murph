Status: completed

Updated: 2026-07-10

## Goal

- Move Murph's ReviewGPT tooling onto the published `@cobuild/review-gpt@0.5.102` patch so PR reviews use the guarded `codebase.zip` attachment without generating Repomix by default, while retaining the `0.5.101` model-confirmation regression fix.

## Success criteria

- Root dependency metadata and the lockfile resolve `@cobuild/review-gpt@0.5.102` from the public registry.
- The minimum-release-age exception is narrowed from `0.5.100` to exactly `0.5.102`.
- The repository's release-policy proof expects the new package and age-exception versions.
- The installed ReviewGPT CLI reports `0.5.102`.
- Dependency guards, frozen install, diff-scoped verification, and required completion audits pass with no unresolved actionable findings.

## Scope

- In scope: root `package.json`, `pnpm-workspace.yaml`, and `pnpm-lock.yaml` dependency metadata for ReviewGPT, plus the matching release-policy test expectation.
- Out of scope: Murph ReviewGPT prompts/configuration, unrelated dependency upgrades, and concurrent workflow/preset changes.

## Constraints

- Technical constraints: use the public npm release; preserve pnpm's supply-chain controls; update the exact release-age exception and lockfile together.
- Product/process constraints: preserve unrelated working-tree edits and finish through the plan-aware scoped commit path.

## Risks and mitigations

1. Risk: npm visibility or pnpm's release-age gate leaves Murph on a stale or partially resolved package.
   Mitigation: verify the registry version first, replace the exact age exception, perform a normal pnpm update, and prove the frozen install and installed CLI version.
2. Risk: the root manifest update changes unrelated transitive dependencies.
   Mitigation: inspect the manifest and lockfile diff, run dependency guards/audit, and reject unrelated lockfile churn.

## Tasks

1. Confirm the patch release and npm `latest` tag.
2. Update the root dependency, exact release-age exception, and lockfile.
3. Run dependency, frozen-install, CLI-version, and diff-scoped verification.
4. Run required security/privacy and coverage-write audits, then parent final review.
5. Close the plan and create the scoped commit.

## Decisions

- Keep the existing caret manifest style while pinning the release-age bypass to the exact new patch.
- Do not change Murph's ReviewGPT model or prompt configuration; this rollout is dependency-only.
