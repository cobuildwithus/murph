# Public area paintings for recorded routes

Use the committed route card's public three-by-two tile frame as the identity
of a shared painting. Keep paths and measurements in the sealed health post.
The phone overlays the path and can use its native map while art is unavailable.

- Reconstruct the frame from its validated key in both the painting and read paths.
- Share the game painter and its existing claim, budget, deadline and finish rules.
- Schedule a job for a newly committed route post with a kept map. Check the
  member's current access, consent, post and card before asking each provider.
- Verify the public-frame request, edits and withdrawals, early fallback,
  concurrent claims, byte reads and existing game behavior with synthetic inputs.

The focused tests exercised publication through authenticated JPEG retrieval
with an isolated PostgreSQL database and synthetic provider images. They also
covered consent withdrawal before the claim and between provider calls, post
deletion, map removal, and a caption edit that retained the map. The web
typecheck, lint, documentation drift check and complexity check passed.
