# Interactive voice orb design study

Status: completed
Created: 2026-09-20
Updated: 2026-09-20

## Goal and scope

Add a playable voice-inspired orb at `/design?tab=voice-orb`. Keep all state local to the study; no microphone, assistant connection, network call, or persisted preference. Existing design tabs remain intact.

## Design and implementation

Native WebGL renders soft flowing clouds inside a circular silhouette. Iris follows the requested violet reference; Ember and Sage offer warm alternatives. The light paper stage can switch to a dark surface. Clicking toggles a clearly labeled visual demo state. Native controls adjust palette, drift, cloud detail, and size, with pause and reset.

The renderer pauses offscreen, in background tabs, and with reduced motion. A CSS orb remains visible without WebGL or during context loss. GPU resources and listeners are released on unmount.

## Planned journeys and verification

- Desktop: open the new tab, interact with the orb and every control, pause/resume, reset.
- Phone: no horizontal overflow; the orb and controls remain reachable.
- Keyboard: visible focus, Enter/Space activation, radio and range operation.
- Reduced motion and absent/lost WebGL: useful static presentation and functional controls.
- Run hosted Web typecheck, browser proof, and complexity diff. Inspect rendered captures and the complete diff before a scoped commit.
