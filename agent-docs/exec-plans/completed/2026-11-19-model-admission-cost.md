# Bound live deploy admission cost

Run a real image- and web-enabled Luna turn on each candidate. Reuse a full
matrix proof only on the same UTC day, under the same protected workflow,
OpenAI credential and request-producing inputs. Only a successful production
matrix may issue a proof for a subsequent release. Verify invalidation,
negative receipts, historical cost and production behavior.

The pinned production CLI produced identical SHA-256 fingerprints across two
independent, network-isolated collections of all twelve serialized requests.
Negative tests cover incomplete native capture, changed catalog/request
settings, changed authorization, missing live receipts and forged rendered
proof. A cadence replay of 217 successful workflows projects 66 full and 151
repeat checks with stable credentials and native payloads. Measured input
sizes imply approximately $0.47 per full deployment and $0.0045 per repeat,
including two serving checks. Actual invoices depend on usage and routing.
