# Painted run privacy and admission

A member can publish a route and share a painting with other posts in the same
three-by-two tile frame. The tile coordinates stay in the sealed route card.
Use the existing hosted opaque-ID keyring to identify a painting. Keep the
native map available during preview and when a painting is unavailable.

Limit each member to five new area claims per UTC day. A post that loses
admission before a provider call releases its claim and quota. A later member
with a retained map can claim the area immediately. Concurrent jobs must
preserve the winning claim and both allowances.

routes and providers. Check exact log arguments on background failure. Run the
focused art and Health wins tests with fresh PostgreSQL storage, the Web
typecheck and lint, and documentation drift.
