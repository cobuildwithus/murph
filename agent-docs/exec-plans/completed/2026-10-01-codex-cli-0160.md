## Outcome and invariants

Upgrade the assistant-engine package and hosted runner to stable Codex 0.160.0. Preserve the native public Live patch, input ownership, sandbox helpers, provider egress restrictions, model selection, and existing App Server integration.

## Scope and ownership

Murph owns the package pin, lockfile, image source/checksum and base tag, patch, and reviewed provider-route inventory. No new state owner or runtime abstraction is needed. Production deployment and publishing are outside this repository update.

## Evidence and approach

Official release notes and the npm latest tag agree on 0.160.0. The current pin is 0.156.1. Rebase the existing patch onto the verified release source, retain upstream changes, update coupled pins and current documentation, and regenerate the lockfile with existing supply-chain controls.

## Risks and proof

The native patch conflicts with changed upstream realtime code and generated schemas. Review each conflict, run patch applicability and focused native tests where available, and exercise real App Server protocol/provider conformance plus container-image contracts. Run affected typechecks and dependency checks. New containers receive the new binary; warm containers retain their old binary until deployment replaces them. No persisted data migration is introduced. Exact-image Linux build/sandbox proof remains required before deployment.

## Tasks

1. Verify source, port patch, and update coupled version owners.
2. Install dependencies and run focused compatibility tests and typechecks.
3. Review privacy and the complete diff, record evidence and limitations, and commit the scoped update.
