# Murph Age Ordinary Submitter Source Routes

## Goal

Make ordinary 16-50 lab plus activity/wearable submitter fit explicit in the tracked Murph Age source-route registry, so the model pipeline can prioritize sources that match realistic user submissions.

## Scope

- Add typed ordinary-submitter fit metadata to source routes.
- Add a helper that lists lab plus wearable/activity source routes by ordinary-submitter rank.
- Add focused tests for ordering, filtering, clone safety, and registry validation.

## Non-Goals

- No row-level source access or parsing.
- No product authorization, product display, or score-bearing wearable contribution.
- No source text, private paths, source variable names, predictions, coefficients, or model parameters.

## Verification

- Health-metrics tests.
- Health-metrics typecheck.
- Repo smoke check.
