# PR 337 ReviewGPT round 8 fixes

## Goal

Resolve the accepted ReviewGPT round 8 Linq outbox retry authority finding
for PR 337 without adding new schedulers, jobs, route owners, or broad
architecture.

Success criteria:

- Route-scoped Linq outbox retries keep the durable route-authority tuple
  after the original Linq wake is gone.
- Every route-scoped Linq provider dispatch attempt revalidates that authority.
- The contact-card after-outbound hook can run after a successful eligible
  retry using the same authority.
- Focused tests and required verification pass, then ReviewGPT is rerun.

## Scope

- In: persisted outbox authority metadata, hosted runtime delivery/context
  resolution, focused callback tests.
- Out: new retry queues, new web/runtime route owners, new cron jobs,
  provider API changes, or a redesign of assistant outbox delivery.

## Plan

1. Add a narrow optional persisted external-thread route authority to assistant
   outbox intents.
2. Populate it only when hosted runtime has a Linq route authority for the
   queued delivery.
3. Prefer persisted authority over current wake reconstruction for retry
   dispatch and contact-card side effects.
4. Fail closed when a prepared background Linq route retry has no route
   authority to revalidate.
5. Add regression tests for non-Linq wake retry authority and contact-card
   sharing after retry success.
