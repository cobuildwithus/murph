# Hosted Codex Explicit Snapshot Files

## Goal

Remove the last snapshot-time scalability hazard in hosted Codex continuity by snapshotting manifest-required Codex rollout files as explicit files instead of discovering them through recursive `.codex-hosted` directory walking.

Success criteria:

- `snapshotHostedBundleRoots()` has a small generic explicit-file capability that reuses the same archive entry, externalization, dedupe, and deterministic serialization path as recursive files.
- Hosted full/base and hot-state snapshots include active Codex rollout JSONL files through explicit manifest/prepared-thread paths.
- The operator-home recursive walker no longer admits `.codex-hosted` ancestors just to find rollout files.
- Explicit files reject traversal, missing files, directories, final-file symlinks, and parent symlink segments.
- Existing restore-side Codex manifest verification remains fail-closed.
- Tests prove crowded Codex rollout directories are not recursively scanned for exact rollout inclusion.

## Scope

Primary files:

- `packages/runtime-state/src/hosted-bundle-node.ts`
- `packages/runtime-state/src/hosted-bundles.ts`
- `packages/runtime-state/test/hosted-bundle.test.ts`

Possible verification-only or overlap-aware files:

- `packages/assistant-runtime/src/hosted-runtime/workspace-restore.ts`
- `packages/assistant-runtime/test/hosted-runtime-workspace-restore-codex-continuity.test.ts`

Coordination-only files:

- this plan

## Approach

Add explicit files as a generic root-level snapshot option rather than a Codex-specific branch in the bundle writer. Keep Codex policy in `hosted-bundles.ts`: the continuity collector decides which rollout paths are required, and the bundle layer only validates and materializes exact files.

Implementation outline:

1. Extend `HostedBundleSnapshotRootInput` with `explicitFiles?: readonly string[]`.
2. Collect explicit files by direct path after recursive collection for an included root.
3. Validate each explicit file with the existing bundle path normalization and symlink-safe path walk.
4. Pass explicit files through `externalizeFile` and `includedPaths` dedupe.
5. In hosted snapshot builders, pass `.codex-hosted/${rolloutRelativePath}` as explicit files and stop allowing `.codex-hosted` through the operator-home include predicate.
6. Keep `.murph/hosted-codex-continuity.json` generated by `hosted-bundles.ts`, not discovered from disk.
