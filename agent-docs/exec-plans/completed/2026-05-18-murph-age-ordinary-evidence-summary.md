# Murph Age Ordinary Evidence Summary

## Goal

Summarize batches of ordinary lab plus wearable/activity aggregate evidence cards so autoresearch can tell which ranked sources are ready and which top routes still need receipts.

## Scope

- Add a health-metrics helper that assesses multiple aggregate evidence cards.
- Return ready source route ids, missing source route ids, and per-card assessments.
- Add focused tests for ready and blocked receipt batches.

## Non-Goals

- No source data access, row parsing, model promotion, product display, or wearable score contribution.

## Verification

- Health-metrics tests.
- Health-metrics typecheck.
- Repo smoke/typecheck if practical.
