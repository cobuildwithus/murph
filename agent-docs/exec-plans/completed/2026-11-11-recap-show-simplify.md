# Simplify pair recap authoring

## Outcome

One normal hosted group turn reads authorized material, generates local media,
and submits one draft. Keep presentation decoding, source authorization, atomic
publication/replay, asset retirement, outbox delivery and Ops regeneration.
Initial failure publishes canonical text; failed replacement preserves the
existing recap and silently retires its delivery receipt.

## Decisions

- The task's owner overrides the supplied deletion plan: normal sandbox/cwd/tools;
  six forwarded media requests counted once in memory; no durable budget or
  phased protocol compatibility. No changes from superseded PR #4834 are copied.
- Delete admission/reservations/pricing/deadlines, frozen selections and provider
  receipts, preview/CLI/renderer, pair-show editorial guards, and lore stamps.
- Keep host-owned source IDs associated with generated byte hashes, safe file
  reads, bounded transfer, current source authorization and private media storage.
- Deliver material through the normal read tool; reference bytes remain host-only.
- Deploy Web then runner; drop the unused runtime-owner column through the
  existing post-deploy contract migration mechanism. No in-flight recap support.
- No production access, regeneration, ReviewGPT, merge or deploy.
