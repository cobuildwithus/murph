### Optional questions and workout sources

Generation 22 serves thirty age- and sex-eligible habit questions after the existing check-ins. The canonical assessment stores a versioned closed choice, including explicit skips. Dated corrections and expiry govern both the next question and historical scoring. Fried chicken, fried seafood, widespread pain and chewing changes can be supplied through the canonical answer contract by another surface. The You view does not prompt for these four. Waist/hip and thigh measurements require a specified tape protocol and have no entry route.

WHOOP scored workouts with all six durations supply fractional minutes per original zone. The model requires standard ranges confirmed as of the workout. Junction sessions can preserve original provider bins for Apple Watch, Garmin and Fitbit/Google. Apple Watch and Garmin also need the actual lower heart-rate-reserve fractions, which the current import does not provide. BPM bounds alone are insufficient. Apple Health relay attribution alone cannot establish the original instrument. Fitbit/Google requires a calibrated provider mapping before its bins can affect this model. Daily totals and absent or incomplete bins stay unknown. Older native WHOOP sessions without canonical bins need the original scored workout to be reprocessed by the upgraded importer and a fresh replica published.

The eight clinical instruments (teeth rating, complete tooth loss, chair difficulty, hospitalization, distress, word recall, eyesight and coronary calcium), hearing, distance vision and untreated sleep apnea still lack the required typed observations. Bilateral maximal grip, verified step-test protocols and minute-level step wear windows need explicit source measurements. A questionnaire response about remaining natural teeth has its own protocol and factor.

## Views and history

Unsupported profiles pause. A reference-only profile, an out-of-range equivalent age, an ambiguous eligibility year, or a single proxy or published factor without independent corroboration yields a building headline. Factors use member-facing units. Goals appear for measurements with an actionable aim. Directional norms show Top N% only from the favorable 60th percentile. Combine results include completed and skipped station counts and need three completed stations before displaying an age effect.

Repeated observations gradually revise the headline. The weekly comparison measures recent changes against earlier observations on the same instrument. The interval reflects the missing measurements in the reference examination panel.

Each historical point uses dated evidence available by the evaluation day. Comparable factor changes at fixed chronological age determine weekly modeled days. A reference-only week shows 7.0 days, carries a partial flag and has empty helped and cost lists. New evidence contributes to the reconstructed line. Event labels mark blood draws, Combine sessions, completed food weeks and the first qualifying blood pressure series, once per kind per calendar week. Weekly factor rows appear from 0.05 days in either direction.

One sealed row per member holds the view bundle. Its dependency binds the member, model and schema versions, immutable publication, data version, verified game inputs, local date and zone. Conditional publication protects against stale writers. The next replica publication makes canonical check-ins visible. Private read authority is checked before and after serving the response. The challenge list and working-on rows load separately.

Run `python3 -B apps/web/scripts/health-you/reference.py <R17-directory>` to import the frozen aggregates and all 1,071 invented research cases with history. The colocated parity suite compares complete outputs. The research Node verifier accepts an ES module exporting `fromRaw` from the same engine.
