## Design Context

For product positioning, target audience, and brand voice see `agent-docs/product-marketing-context.md`.

### Brand Personality

**Clean. Precise. Scientific.**

Named after Murph from Interstellar — the physicist who solved the equation. The brand carries that energy: curiosity-driven, rigorous, warm underneath the science. Not cold or clinical. Not gamified or cheerful. A tool for someone who takes their health seriously and wants real answers.

### Aesthetic Direction

**Visual tone:** Scientific minimalism with warm desert palette. Calm futurism — not cyberpunk, not neon, not corporate. Think: a research station on a quiet planet. Space to breathe. Precision in every element.

**Film reference — Interstellar:**

- Chalkboard with equations → data displayed as structured formulas, not flashy charts
- Bookshelves → experiment library as a shelf of knowledge
- The Hamilton watch → time as a precious artifact, metric tracking with analog precision
- Color world: dark slate, warm amber, muted sage, cream, dark wood

**Web references:**

- Betalix: desert landscapes, warm sand tones, vast space, lone figure, spacious layout, large typography
- Arcus: black/white editorial, serif typography, generous whitespace, large stat numbers, direct copy ("Decisions, not reports")

**Anti-references (never do this):**

- Generic health apps (Oura, Fitbit) — ring charts, gamification, "great job!" messages
- SaaS dashboards (Mixpanel, Amplitude) — gray boxes, corporate tables, metric overload
- Anything neon, cyberpunk, or Blade Runner
- AI slop — generic gradients, purple-blue tech aesthetic, meaningless hero illustrations

**Color palette (established):**

- Background: cream #f5f0e8
- Primary text: slate #2d3436
- Muted text: #736a58 (WCAG AA compliant on cream)
- Warm sand: #d4c4a8, amber #c4a882
- Positive/growth: sage #7a8c6e, dark sage #5a6e32
- Warning: warm sienna #8b5d3f (WCAG AA compliant on cream)
- Borders: rgba(196,168,130,0.25)
- Cards: rgba(255,252,246,0.9)
- Sidebar: gradient from #2d3436 → #3a2e24 → #2a1f16 (warm wood)
- CTA button: #5a6e32 (green) for "Start Experiment", #2d3436 for secondary actions
- Light mode primary. Dark mode later.

**Typography (established):**

- Headings: Fraunces serif, 600 weight, tight tracking (-0.03em)
- Body: DM Sans, 14-16px
- Labels/mono: DM Mono, 9-11px, letter-spacing 0.1-0.12em, uppercase
- Large stat numbers: Fraunces 32px+ (data as poetry)

**Layout (established):**

- Desktop-first, 1440px artboards
- 240px sidebar with warm gradient
- Content padding: 56px horizontal, 36-48px vertical
- Section gaps: 32-40px between major sections
- Card border-radius: 10-12px
- Two-column layouts for Protocol + Why It Works, Charts + Timeline

**Icons:**

- Lucide Animated (`https://lucide-animated.com`) — animated SVG icons via Motion
- Install: `pnpm dlx shadcn@latest add https://lucide-animated.com/r/{icon-name}.json`
- Use sparingly, restrained motion. Icons serve comprehension, not decoration.

**Transitions:**

- Use View Transitions API (`<ViewTransition>` from `next/navigation`), not React Motion / Framer Motion.
- Page transitions, tab switches, list reorders — all through native View Transitions.
- Keep transitions subtle and fast. No decorative animations.

**Photography style:**

- Desert homestead aesthetic — rustic, warm, analog film grain
- Contextual per experiment: ice bath for cold, sauna bench for heat, desert trail for cardio
- Muted earth tones, no people, quiet and calm
- Stored in `apps/web/public/design-assets/`

**Image generation prompt template:**

Use this structure when generating hero images with `/nano-banana-2` or similar tools:

```
A [subject] in a desert homestead setting. Rustic wooden furniture, adobe
or plaster walls, warm golden hour light. Shot on medium format film,
slightly desaturated earth tones — cream, sand, warm brown, muted sage.
No people. Quiet, contemplative mood. Shallow depth of field. Style
reference: Kinfolk magazine, Joshua Tree cabin interiors.
```

Replace `[subject]` with experiment-relevant content:
- Sauna: "rustic wooden sauna bench with a folded linen towel and dried eucalyptus bundle"
- Cold exposure: "wooden barrel ice bath on a desert porch at golden hour, mountains in background"
- Sleep: "bedside table with amber supplement bottle and ceramic bowl of capsules, linen curtain"
- Cardio: "wooden rocking chair on a desert porch overlooking arid mountains at sunset"
- Nutrition: "ceramic plate with whole foods on a rough-hewn wooden table, window light"

Key constraints: no text overlays, no logos, no people, no clinical/medical look. The image should feel like a page from a design magazine, not a health app.

### Key UI Patterns (established)

- **Experiment detail tabs:** "Protocol" and "Your Results"
- **Your Results — two states:**
  - **Active:** Progress bar (Baseline → Active → Analysis, sage green fill), 38% completion ring, Next Step card, signal cards, trend charts + timeline side by side, Conclusions section placeholder ("Available after experiment ends").
  - **Finished:** Summary card ("Strong positive signal"), signal cards with final values + expected ranges, trend charts + timeline, Conclusions section (What worked, What didn't change, Key Insights, Recommendations).
- **Progress bar:** 3-phase (Baseline · 7d ✓ → Active · Day X of Y → Analysis). Sage green fill, mono labels, active phase bold.
- **Signal cards:** Large Fraunces numbers + unit + delta in sage green + expected range from Protocol. In finished state: "was X" baseline value.
- **Trend charts:** SVG sparklines with baseline (dashed #d4c4a8) vs active (#7a8c6e) phases, shaded baseline region.
- **Timeline:** Vertical dot timeline with upcoming (faded opacity) at top + history below. Event types: sessions (green dot), milestones (green dot), skipped (sand dot), checkpoints (ring), start (filled dark green), end (filled green).
- **Next Step card:** Sage green left accent bar, session title, when, context, "Next session: Friday" on right. Only in active state.
- **Conclusions:** 4 structured cards stacked vertically — What worked (sage green accent), What didn't change (neutral), Key Insights (bullet points), Recommendations (sage green accent with → arrows). Only in finished state.
- **Research section:** Summary stats (studies, participants, years, evidence level as "5/5") + study cards with OBS/RCT/MA round badges.
- **Expert cards:** Avatar initials in sand circle + name + field + quote.
- **Safety section:** Caution rating dots + "Who should avoid" + "Precautions".
- **Start Experiment button:** Green (#5a6e32), large rounded-2xl, with subtitle "7-day baseline · X-day protocol".

### Design Principles

1. **Respect intelligence.** No tooltips explaining what HRV means. No gamification. No "great job!" messages. The user is a scientist running experiments on themselves.
2. **Space is content.** Whitespace is not wasted space — it creates focus. Every element earns its pixels. When in doubt, remove.
3. **Data as poetry, not dashboards.** Present metrics like equations on a chalkboard — structured, beautiful, meaningful. Not pie charts in gray boxes.
4. **Warm precision.** Scientific rigor with human warmth. The interface should feel like a well-lit research library, not a hospital or a server room.
5. **Show, don't decorate.** No gradients for gradients' sake. No rounded-corner cards because "modern." Every visual choice serves comprehension or emotion.
6. **Content density over minimalism.** Scientific data, expert quotes, research citations, mechanism explanations — the depth IS the product. More information, presented with care.
